# 环线标志

维护者于 2026-10-13 提供游戏截图并指定使用其中的专用标志：一／二／三道杠对应一／二／三环。

`gun-marks.png` 为透明 PNG atlas（2172×724，依次一／二／三环），由内建 imagegen 以维护者截图为编辑目标提取，并清理外沿；深棕内底保留，不属于应移除的背景。`GunMarksBadge.vue` 通过 SVG viewBox 呈现对应区域，保持同宽与自然高度；显示时按各档不透明图案的中心对齐，避免一／二环因图集上方留白而靠下。SVG 的 PNG 图集通过显式 `?inline` 导入为 data URL，不受全局 `assetsInlineLimit: 0` 影响；SVG 自包含，html2canvas 生成 PNG 时不丢失外链图片。三档共用资产，普通 UI 使用 16×20 屏幕像素，回放名牌使用 12×16 以保留既有行高。

最终编辑提示词：只清理外沿散点、粗糙边和光晕，保留金黄色边框、深棕内底、原有图形；左／中／右严格一／二／三道上扬杠，三格同宽、底部对齐，外部全透明，不添加文字、阴影或坦克背景。使用内建 imagegen，未使用 CLI 或额外 API 凭据。

数据只来自回放 `players[].gun_marks`；0 环不显示图标，缺失／非法保持未知。环数是已获得的车辆成就，不能表示当前精确百分位。
