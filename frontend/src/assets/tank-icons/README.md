# 战局回放坦克标记

AI Review「战局回放」的俯视坦克标记素材。当前生产方案统一使用半立体 MT 模型，并拆成可独立旋转的车体与炮塔两层：

- `tank-marker-hull.png`：透明车体层，`512 × 512`，车头朝上。
- `tank-marker-turret.png`：透明炮塔层，`512 × 512`；炮塔外壳与完整炮管是不可拆分的刚性整体，炮口朝上。
- `tank-marker-state-spec.png`：状态、姿态、层级和尺寸规范原图，仅供设计与实现参考，不应由运行时加载。

两张运行时 PNG 使用相同画布和旋转轴：

- 旋转中心均为画布中心 `(256, 256)`，叠加时两层左上角必须重合。
- 车体层按 `hullYaw` 旋转；炮塔层按炮塔世界方向旋转。若回放只提供相对角，则先计算 `turretWorldYaw = hullYaw + turretRelativeYaw`。
- 只旋转完整炮塔层；禁止只旋转炮管、修正炮管角度或让炮管与炮塔外壳分离。
- 历史轨迹只表达车辆曾经的位置，不推断车体或炮塔朝向。
- 最后已知状态只使用透明灰，不添加时钟图标。
- 推荐地图显示尺寸为 `28px`；阵营色、选中、低血量、阵亡、悬停和录像者标记由消费组件以 CSS 滤镜或独立 UI 覆盖层表达。
- 无障碍名称与车辆状态由消费组件提供；地图上的装饰性实例应设置 `aria-hidden="true"`。

目录中的四个 SVG 是早期车型轮廓方案，仅为兼容现有评审记录保留；新实现不得把它们作为默认战局标记。
