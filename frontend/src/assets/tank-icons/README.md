# 战局回放坦克标记（素材契约）

AI Review「战局回放」的俯视坦克标记素材契约。最终方案为**通用半立体 MT 双层模型**：
可独立旋转的透明车体层与透明炮塔层（炮塔外壳 + 完整炮管为刚性整体）。

## 交付范围

本 PR 仅交付本契约文档。运行时 PNG 需由持有 authoritative master 素材的会话基于同一 master
拆层生成后合入（当前仓库/工作区无 master，无法同源拆层，故不提交不合格二进制）。

## 目标素材规格（接入时须满足）

- `tank-marker-hull.png`：车体层，`512 × 512`、8-bit RGBA 真透明 PNG，车头朝上（0° 基准）；
  含完整车体与履带，不含炮塔。
- `tank-marker-turret.png`：炮塔层，`512 × 512`、8-bit RGBA 真透明 PNG；炮塔外壳与完整炮管是
  不可拆分的刚性整体，禁止独立炮管层，炮口朝上（0° 基准）。
- 两层共享画布中心 `(256, 256)`；叠加时左上角重合，0° 组合必须正确覆盖炮塔座圈。
- 炮塔绕 `(256, 256)` 旋转 0°/90°/180°/270° 不得漂移或绕圈；四边保留透明 padding，
  炮管、履带、阴影与抗锯齿边缘不得被裁切。
- 友军/敌军各一对确定性素材（`tank-marker-{friendly,enemy}-{hull,turret}.png`）：
  友军暖金/琥珀色，敌军冷青蓝色；敌军由友军做确定性颜色变换生成，只允许改变颜色，
  alpha/几何轮廓/尺寸/旋转中心逐像素一致，保留黑色履带、阴影与高光层次。

## 旋转与方向术语（统一契约）

- 车体层按 `hullYaw` 旋转。
- 炮塔层按 `turretWorldYaw` 旋转，其中 `turretWorldYaw = hullYaw + turretRelativeYaw`。
- 只旋转完整炮塔层；禁止只旋转炮管、修正炮管角度或让炮管与炮塔外壳分离。

## 接入边界与显示规则

- `hullYaw` / `turretRelativeYaw` / `turretWorldYaw` 是**未来播放器接入契约**：当前 PR #71
  的 `BattlePlayback.vue` 仍使用圆点标记，DTO 尚未提供方向字段；本契约合入后播放器不会自动
  使用这些素材，实际接入、方向字段与双层旋转属于后续播放器变更。
- 历史轨迹只代表车辆曾经的位置，不代表车体或炮塔朝向。
- 最后已知状态只使用透明灰，不添加时钟图标。
- 录像者、选中、低血量、阵亡、悬停属于 UI overlay，不烘焙进基础 sprite。
- 推荐地图显示尺寸为 `28px`；阵营色、选中、低血量、阵亡、悬停和录像者标记由消费组件以
  CSS 滤镜或独立 UI 覆盖层表达。
- 无障碍名称与车辆状态由消费组件提供；地图上的装饰性实例应设置 `aria-hidden="true"`。
