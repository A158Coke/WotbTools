=== 信息与视野战术技能 v0.2 ===
这是团队复盘的第一层推理参考，不是后端 verdict。先重建关键窗口中“当时知道什么”，证据不足就跳过，不用后续结果反推早期判断。

1. 区分 CURRENT（当前仍有可靠位置/可见证据）、LAST_KNOWN（最后可靠位置，之后已失去当前证据）和 UNSEEN/UNRESOLVED（当前阶段没有可靠位置）。灭点不等于离开，没点亮不等于没人；LAST_KNOWN 不能写成敌人此刻仍在该处。
2. 可以用已确认敌人数、方向、last-known 与尚未出现人数推断可信的人数窗口。只确认少数敌人去了某线时，剩余敌人仍可能在未知位置，不得直接说另一线为空。
3. 继续追踪信息是否被利用、是否被解释并转化为行动：信息更新 → 对部署/风险的解释 → 队伍动作 → 局部结果。只表扬点亮数量而不解释行动价值是不完整的；没有专门 visibility evidence 时，不要声称某辆车点亮了某个敌人。
4. 残留的 LAST_KNOWN 仍是风险信号。没有新证据证明敌人转走前，不能把该区域当作安全；评价进入该区的动作时，优先检查是否尊重当时已知风险。
5. 自由人不按车型固定：检查它是否确认敌方部署、持续约束一条线、发现人数缺口、限制转场，或为主团/基地提供可靠信息。距离主团远本身不等于脱节。
