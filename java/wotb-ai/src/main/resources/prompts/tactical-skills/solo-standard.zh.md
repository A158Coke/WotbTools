=== 随机战个人复盘规范 v1.1（Coach Lab） ===
来源：Coach Lab 用 2026 国服夏季赛四强 34 局（3 名录像者）按个人视角复盘归纳的规则，这里只保留本提示的输入能判定的部分。样本来自高水平赛事，不代表随机战玩家的水平，不得把它当成本局的先验。只评你本人；队友的站位和配合不归你负责。与本提示其他规则冲突时，证据边界规则优先。

一、判定
1. 每个关键动作只给三种结论之一：失误 / 正确 / 无法判定；“无法判定”必须写明缺哪条数据。
2. 数据边界：输入没有完整的开炮记录、瞄准目标和装填弹药数据，只有命中造成的伤害事件。没有伤害记录不等于没开炮，不得据此判“没回击”“晚开炮”“打错目标”或“对方装好弹”。
3. 枪法、击穿和交火效率只按本局证据判断（你对谁造成了多少伤害、被谁打中多少），不套用任何外部样本的命中率、击穿率或权重。
4. 每条失误写清：事实（时间、对手坦克名称、距离、伤害）→ 为什么 → 应该做的动作 → 证据边界。只写本局最大问题作为一句话结论。

二、规则
5. 谁在打你先处理谁：同一辆敌车在约 40 秒内打中你 3 发以上，期间你一直留在它的炮线里（位置没有离开、它继续命中）。判失误要同时满足：在后面几发之前，它的方向对你已经已知（它 CURRENT，或之前的命中已经暴露了这条炮线）；当时有可行的安全脱离路线或换位位置。失误的内容是持续暴露在已知炮线里，应该换到它打不到的位置；回击只能写成可选方案，不能写成你没做（开炮和未命中不在数据里）。你对它有没有造成伤害只作为交换结果描述，不作为判失误的依据。不满足时只描述“持续被它命中”，不判失误。高处、侧面、身后的轻坦最常见。
6. 一次只露给一辆车：约 2 秒内被两辆不同的敌车打中，只说明你进入后形成了交叉火力，本身不证明前压是错的。只有前压前至少两条威胁已经 CURRENT 或可靠的 LAST_KNOWN（或之前的命中已经暴露了对应炮线），当时有更安全的可行选择，而你仍从停着不挨打的位置主动往前开进去 → 失误；否则只描述“前压后进入交叉火力”，不判前压本身。被对方推进或绕后形成的交叉火力不算你的失误，看你之后有没有离开。
7. 野队队友不可靠：随机战队友的可信度远低于联赛，判断你的决策时不能默认队友会跟上、补位、守住某条线或替你打掉威胁。队友支援只有在决策当时有正向证据时才算进你的选项：队友对相关敌车的实际命中可以直接证明当时有支援炮线；否则要由 CURRENT 位置加上可证明的 LOS/遮挡、目标可用性和到位时间共同支撑，位置或距离单独不够。判“依赖了未到位的队友”要有决策当时的正向位置/时间证据，证明队友确实不在能支援的位置（例如 CURRENT 位置很远、到位时间明显晚于你的暴露），并且当时有不依赖队友的更稳妥选择 → 失误；判的是依赖本身，不得从队友后来没来或数据缺失反推。覆盖不全（OBSERVED_DAMAGE_IS_PARTIAL）时，没有命中或交火记录不能当成队友没在支援，只能判无法判定。队友自己的失误和缺位不算你的失误。
8. 对结果没有影响的终局阵亡不判定。
