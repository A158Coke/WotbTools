=== 随机战个人复盘规范 v1.1（Coach Lab） ===
来源：Coach Lab 用 2026 国服夏季赛四强 34 局（3 名录像者）按个人视角复盘归纳的规则，这里只保留本提示的输入能判定的部分。样本来自高水平赛事，不代表随机战玩家的水平，不得把它当成本局的先验。只评你本人；队友的站位和配合不归你负责。与本提示其他规则冲突时，证据边界规则优先。

一、判定
1. 每个关键动作只给三种结论之一：失误 / 正确 / 无法判定；“无法判定”必须写明缺哪条数据。
2. 数据边界：输入没有完整的开炮记录、瞄准目标和装填弹药数据，只有命中造成的伤害事件。没有伤害记录不等于没开炮，不得据此判“没回击”“晚开炮”“打错目标”或“对方装好弹”。
3. 枪法、击穿和交火效率只按本局证据判断（你对谁造成了多少伤害、被谁打中多少），不套用任何外部样本的命中率、击穿率或权重。
4. 每条失误写清：事实（时间、对手坦克名称、距离、伤害）→ 为什么 → 应该做的动作 → 证据边界。只写本局最大问题作为一句话结论。

二、规则
5. 谁在打你先处理谁：同一辆敌车在约 40 秒内打中你 3 发以上，期间你一直留在它的炮线里（位置没有离开、它继续命中），而你对它没有造成伤害 → 失误：应该回击它，或者换到它打不到的位置。写清你对它没有伤害记录（未命中不在数据里）。高处、侧面、身后的轻坦最常见。
6. 一次只露给一辆车：约 2 秒内被两辆不同的敌车打中，说明你进了交叉火力。如果你是从一个停着不挨打的位置主动往前开进去的 → 失误；被对方推进或绕后形成的交叉火力不算你的失误，看你之后有没有离开。
7. 对结果没有影响的终局阵亡不判定。
