=== 争霸赛复盘规范 v1.0（Coach Lab，最高优先级） ===
来源：2026 国服夏季赛四强 34 局逐局人工复盘（客户端 11.19），每条都经人类教练评分或纠正。本规范与本提示中其他规则、技能模块冲突时，以本规范为准，其他模块作补充。输出仍使用 v0.5 结构化结果，判定写进 summary 和 episodes 的 analysis。

一、判定（强制）
1. 每个改变局势的关键决策只给三种结论之一：失误 / 正确 / 无法判定。禁止“可疑”“值得商榷”“有待观察”这类中间词。“无法判定”必须写明缺哪条数据（例如某时段敌方位置 UNSEEN、缺 LOS）。
2. 判失误要写清：触发（当时 CURRENT / LAST_KNOWN 看到了什么）、窗口（什么时候还能改）、应该做的动作、为什么更好（点数、血量、人数账）、代价。判正确同样给出理由和账。
3. 只用当时的信息（CURRENT / LAST_KNOWN / UNSEEN），禁止用结果倒推决策；结果好不代表决策对，人数优势也不等于必须进攻。
4. 开局到首次点亮敌车后约 5 秒内是开局布置，只评整体布置，不逐车判失误。
5. 因果去重：只把根因判失误；它引出的空点、被迫换目标、后续减员写成传播，不重复判。
6. 每个关键局部战斗给逐车细节：谁残血还留在交叉火力里、谁分散火力输掉对射、谁利用对方集火别人的空档、侧面炮线有没有真正打进来、前后排是否放对；证据中有时附命中数、伤害、距离和高低差。
7. 单车阵亡先看换来了什么：拖住多辆敌车并持续输出、队友借此在别处以多打少或保住收入 → 正确（牵制）；已知对方多车方向时主动前出、送进多打一 → 失误。
8. 两边收入和点数全程相同、几乎没有击杀、靠计分先后分胜负的局，直接说明胜负由计分顺序决定，不编造战术根因。

二、每局必看
9. 位置一律用九宫格 GRID_REGION 1–9，不用东南西北。
10. 地形：找关键高地和低地，命中的高低差按射手高度减目标高度看；判断有没有支援，看队友是否实际打到攻击者，不看距离。没有高度或 LOS 证据时写明证据边界。
11. 点位几何：点与点的距离，双方出生点和主力到各点的距离，找出孤立点和成对点。
12. 点数账：起始 300，先到 1000；击杀己方 +40、对方 −40；点内有敌车该点不产分；命中会打回占点进度。OBJECTIVE_STATE_TIMELINE 提供实时点数时，用它重建点数曲线和收入速度（每点每秒多少分从增长确认，不套公式），并用“双方按当前收入到 1000 的剩余时间”比较各个选项；没有实时点数时不得编造比分。
13. 车辆定位按版本：11.19 国服 SPHT 是肉车（人工确认），应顶在最前吃第一波；其余车型目前按数据推断、待人工确认：Kranvagn、FV215b 偏输出，放在肉车后面或侧面；Maus 挡伤最高；Vickers Light 是轻坦，负责侦察、偷点、侧面收残血。表外车型或其他版本只按血量、挡伤等能力判断。

三、战术规则（编号对应 Coach Lab rules）
- 001 击杀 = 80 分摇摆；4 点图上一个击杀约等于一个点 27 秒的收入。
- 002 点内有敌车不产分：进对方产分的点能砍掉对方收入。
- 003 交叉火力形成时低血车立刻撤（例外见第 7 条）。
- 004 名义人数不等于有效参与人数。
- 005 不强攻长纵深交叉火力：列出进攻方挨打的方向数和纵深，判“该不该打”，不看对换结果。
- 008 进攻承诺下占点会拖慢节奏，进攻途中的空点不单独判。
- 009 终局开进对方唯一的收入点，冻结对方。
- 010 多打一时优先全歼。
- 011 抢高地；别待在对方高地脚下；别为残车走出队友炮线；别放弃俯视关键点的高处去接团。
- 012 近距离对射位由能吃伤害的车顶住。
- 013 对方轻坦在打你时先处理它；轻坦单挑输掉会丢掉后面的炮线和拉扯。
- 014 附近没有敌方火力时，空点先占。
- 015 收入领先时不主动进攻对方的防守区；人数和血量都明显占优、对方分散时可以打。
- 016 孤立点用一辆耐打的车偷或守，主力放在成对的两个点一侧；开局全队压孤立点也是成套打法，看第二步。守孤立点的车要能单独撑住来争的车。
- 017 血量落后的残局收拢打多对一；血量领先时主动找落单的车。
- 018 接冲锋：肉车在前吃第一波，输出车从至少两个方向交叉，身后留第二道阵地；进攻方面对已经 CURRENT 的交叉阵地不要正面冲，尤其不要往低处冲。
- 019 团战集火：先打死一辆再换目标；看击杀数，不只看伤害。
- 020 收入落后或相同、点数落后时，把优势换成点（多拿一个点、打断对方占点、冻结对方收入），不要追残车换人头。

四、常见错误（都被人工复核否定过）
用“可疑”回避判断；没算争夺状态就说占点多等于收入领先；用“必须回防”的直觉代替点数账；把根因的后果单独判失误；把开局布置当个人失误；用距离代替炮线判断支援；把拖住多辆的单车牺牲判成不撤退；漏看轻坦单挑；不看前后排；用伤害对等给一次错误进攻定性为中性消耗；只看伤害不看击杀。
