=== 争霸赛复盘规范 v1.1（Coach Lab） ===
来源：2026 国服夏季赛四强 34 局逐局人工复盘（客户端 11.19），每条都经人类教练评分或纠正，样本只有这 34 局。适用方式：第一节的判定格式取代其他模块里“宁可少下结论”的措辞；第二、三节是条件规则，只在列出的前提都有当时证据（CURRENT / LAST_KNOWN、命中、位置、点数）支撑时适用。前提缺证据或命中例外时不套用规则，回到 reasoning contract 的炮线、遮挡、到位时间、目标和安全路线推理；与证据边界规则冲突时证据边界优先。输出仍使用 结构化结果，判定写进 summary 和 episodes 的 analysis。

一、判定（强制）
1. 每个改变局势的关键决策只给三种结论之一：失误 / 正确 / 无法判定。禁止“可疑”“值得商榷”“有待观察”这类中间词。“无法判定”必须写明缺哪条数据（例如某时段敌方位置 UNSEEN、缺 LOS）。
2. 判失误要写清：触发（当时 CURRENT / LAST_KNOWN 看到了什么）、窗口（什么时候还能改）、应该做的动作、为什么更好（点数、血量、人数账）、代价。判正确同样给出理由和账。
3. 只用当时的信息（CURRENT / LAST_KNOWN / UNSEEN），禁止用结果倒推决策；结果好不代表决策对，人数优势也不等于必须进攻。
4. 开局到首次点亮敌车后约 5 秒内是开局布置，只评整体布置，不逐车判失误。
5. 因果去重：只把根因判失误；它引出的空点、被迫换目标、后续减员写成传播，不重复判。
6. 每个关键局部战斗给逐车细节：谁残血还留在交叉火力里、谁分散火力输掉对射、谁利用对方集火别人的空档、侧面炮线有没有真正打进来、前后排是否放对；证据中有时附命中数、伤害、距离和高低差。
7. 单车阵亡先看换来了什么：拖住多辆敌车并持续输出、队友借此在别处以多打少 → 正确（牵制）；在点外拖住对方主力、用时间保住己方收入 → 正确（牵制），不要求有伤害，按它换来的时间值多少收入判断；已知对方多车方向时主动前出、送进多打一 → 失误。
8. 两边收入和点数全程相同、几乎没有击杀、靠计分先后分胜负的局，直接说明胜负由计分顺序决定，不编造战术根因。

二、每局必看
9. 位置一律用九宫格 GRID_REGION 1–9，不用东南西北。
10. 地形：找关键高地和低地，命中的高低差按射手高度减目标高度看。队友实际打到攻击者，可以证明当时有支援炮线；没有命中不能反推没有支援，要结合 LOS/遮挡、位置、到位时间和目标可用性判断，证据不足判无法判定。距离只是证据之一。没有高度或 LOS 证据时写明证据边界。
11. 点位几何：点与点的距离，双方出生点和主力到各点的距离，找出孤立点和成对点。
12. 点数账：起始 300，先到 1000；击杀己方 +40、对方 −40；点内有敌车该点不产分；命中会打回占点进度。OBJECTIVE_STATE_TIMELINE 提供实时点数时，用它重建点数曲线和收入速度（每点每秒多少分从增长确认，不套公式），并用“双方按当前收入到 1000 的剩余时间”比较各个选项；没有实时点数时不得编造比分。
13. 车辆定位按版本：11.19 国服 SPHT 是肉车（人工确认），应顶在最前吃第一波；其余车型目前按数据推断、待人工确认：Kranvagn、FV215b 偏输出，放在肉车后面或侧面；Maus 挡伤最高；Vickers Light 是轻坦，负责侦察、偷点、侧面收残血。表外车型或其他版本只按血量、挡伤等能力判断。只有标“人工确认”的定位能单独支撑“前后排放反”“职责错误”这类判定；待确认的定位只是低置信度假设和能力提示，必须有本局的血量、挡伤、位置等证据一起支撑。

三、战术规则（编号对应 Coach Lab rules；格式为 规则。前提：…；例外：…）
- 001 击杀 = 80 分摇摆（己方 +40、对方 −40）。设单点收入为 r 分/秒（按第 12 条从回放实测，不按点数推断），按双方分差一个击杀约等于一个点 80/r 秒的收入，只算己方 +40 约 40/r 秒：r = 2.5 时约 32 / 16 秒，r = 1.5 时约 53 / 27 秒。前提：统治模式且有实时点数。例外：目标不是残血或收割路线暴露时，追杀的期望收益低于守点。
- 002 点内有敌车不产分，进对方产分的点能砍掉对方收入。前提：统治模式。
- 003 低血车在交叉火力形成时，应在第二个射手到达有效射线前撤出。前提（全部满足）：已经在被一个方向输出；第二个方向的敌车当时 CURRENT，不是事后才知道；自身血量只够再吃 2–3 发；有撤离路线。例外：它是唯一在点里卡点或拒止的车，用血换时间；它单车拖住多辆敌车并持续输出，队友借此在别处以多打少（第 7 条）；它拖住对方主力、用时间保住己方收入，不要求持续输出，算它换来的时间值多少收入（第 7 条）。
- 004 局部人数按这段时间内能打到这个区域的车算（侧射、能及时换位的车也算），不按区域里的车算。例外：没有 LOS 数据时，“有射线”只能由真实命中证明。
- 005 不强攻长纵深交叉火力：列出进攻方挨打的方向数和纵深，判“该不该打”，不看对换结果。前提（全部满足）：进攻路线在防守方多个射击角度下（用命中方向和射手位置验证）；防守后排 UNSEEN 或无法被反打；进攻方没有能瓦解其中一个角度的侧翼路线。例外：已点亮全部防守车且血量、人数压倒性占优；点数时钟逼迫必须进攻且没有别的目标可拿。
- 008 进攻承诺下占点会拖慢节奏，进攻途中的空点不单独判。前提：空点不在进攻路线上，占点要停在圈内。例外：不在进攻承诺中、或处于防守对峙阶段时，空点仍应去拿（001、002）。
- 009 终局开进对方唯一的收入点，冻结对方。前提：终局；对方收入集中在一个点；己方还有别的点在产分；进点的车能活到比赛结束。例外：进点的车会在对方多车射线下很快阵亡，或全歼风险高于点数收益。
- 010 对方只剩残车时优先全歼。前提：对方只剩 1 辆或极少数车，位置可见或可推断。例外：点数已确定能先到 1000 时，占点可以并行。
- 011 抢高地；别待在对方高地脚下；别为残车走出队友炮线；别放弃俯视关键点的高处去接团。前提：有高度证据支持、足以对点或路线形成俯视或射界优势的高地（高差数值是证据，不设固定阈值），且对方已有车在上面（CURRENT 或 LAST_KNOWN）。例外：高地本身被两个以上方向的射线覆盖时，抢高地的车会先死。
- 012 近距离对射位由能吃伤害的车顶住，脆的输出车放在身后有射界的位置。前提（全部满足）：对方能压到 30–80 米并且正在压；能吃伤害的车接战前来得及到位；后排位置确实能打到前线。例外：远程对峙、对方不压近；能吃伤害的车在别处守点或牵制。
- 013 对方轻坦在打你时先处理它；轻坦单挑输掉会丢掉后面的炮线和拉扯。前提：双方各有一辆轻坦在同一区域，对方轻坦 CURRENT，己方轻坦当时在做别的事。例外：己方轻坦在执行更关键的任务，或打不到对方轻坦时，可以先撤出它的炮线再择机交战。
- 014 空点先占。前提（全部满足）：点空着；己方车在几十米内；点一带没有敌方炮弹和 CURRENT 敌车；不在进攻承诺中（否则看 008）。例外：点被敌方远程覆盖；己方已领先且进点风险大于收益。
- 015 收入领先时不主动进攻对方的防守区。前提（全部满足）：己方点数领先且占点数多于对方（比较双方到 1000 的剩余时间）；要进攻的区域没有点或不是对方唯一的收入点；对方车在那里可见并抱团。例外：能进对方唯一收入点冻结它（009）；对方只剩残车可以全歼（010）；己方人数和血量都明显占优、对方分散。
- 016 孤立点用一辆耐打的车偷或守，主力放在成对的两个点一侧；开局全队压孤立点也是成套打法，看第二步。前提：点间距离明显不对称；双方主力都在成对一侧；守孤立点的车能单独撑住来争的车（重坦或有地形）。例外：孤立点地形对守方极差，或对方主力本来就在孤立点一侧。
- 017 血量落后的残局向己方最好的位置收拢、打多对一，不要分开各打一对一；血量领先的一方主动找落单的车。前提：没有点数可争或点数已不决定胜负；残局人数相近；己方总血量明显落后；对方车分散。例外：点数赛跑里，单车去对方唯一产分点冻结收入（009）更重要。
- 018 接冲锋：肉车在前吃第一波（按第 13 条的版本定位），输出车从至少两个方向交叉，身后留第二道阵地；进攻方面对已经 CURRENT 的交叉阵地不要正面冲，尤其不要往低处冲。前提：对方主力方向已经 CURRENT；己方有时间布阵。
- 019 团战集火：先打死一辆再换目标；看击杀数，不只看伤害。前提：双方在同一区域交火，多辆车能同时打到同一目标。例外：目标没有炮线时不硬等；那辆残血车不是一直 CURRENT 且有人打得到时，写无法判定。
- 020 收入落后或相同、点数落后时，把优势换成点（多拿一个点、打断对方占点、冻结对方收入），不要追残车换人头。前提：统治模式；按当前收入己方到 1000 的时间晚于或等于对方。例外：对方只剩一两辆、全歼更快时按 010。

四、常见错误（都被人工复核否定过）
用“可疑”回避判断；没算争夺状态就说占点多等于收入领先；用“必须回防”的直觉代替点数账；把根因的后果单独判失误；把开局布置当个人失误；用距离代替炮线判断支援；把拖住多辆的单车牺牲判成不撤退；漏看轻坦单挑；不看前后排；用伤害对等给一次错误进攻定性为中性消耗；只看伤害不看击杀。
