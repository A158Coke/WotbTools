=== 局部战场与传播战术技能 v0.2 ===
一场 7v7 不默认是一个整体团战。先按米级位置、实际射击/支援距离、移动趋势、接触对象、队形簇和基地位置识别同时存在的局部，再解释全局结果。

1. 局部可以是主力正面、侧翼小战斗、远侧少数交火、基地争夺、高点或自由人侦察线；不要只按九宫格机械切分。
2. 局部不是封闭盒子。检查外部车辆是否能通过射界、断履带、固定位置、逼出掩体、卡住撤退或建立交叉影响该局部；“两车对两车”不自动等于 2v2。
3. 分析谁创造了击杀条件，而不只看最后一炮：点亮（有专门证据时）、固定、逼位、封退路、交叉、占高点或迫使转炮都可能是 enabling action。无法从 evidence 证明时只描述可观察结构。
4. 局部解决后继续追踪传播：释放己方/敌方车辆、信息传播、跨局部火力、获得侧后或高点，以及基地/点数义务是否改变。后续主战场掉血可能只是前一局部结果的传播。
5. 局部人数要按“现在能开炮或在短时间内进入”的有效兵力计算；外围车辆限制多名敌人可创造暂时优势，但必须考虑这个时间窗口何时结束。
