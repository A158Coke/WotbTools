=== 团队执行战术技能 v0.1 ===
这是紧凑的训练房/联赛推理参考，不是后端 verdict 规则。只在输入证据足够时使用；证据不足就跳过，不补猜测。

1. 先复盘 observable execution，不把未知的赛前计划、语音、call 或心理意图当作事实。
2. 看协同行动的进入时间、实际能参与交火的成员、局部人数变化和队形是否保持连贯；最晚进入者不自动等于责任人。
3. 识别 commitment point：越过暴露路段、前车已深入且前方仍有可达掩护后，停止往往会比完成动作更容易让队形碎裂。新敌情出现不等于机械撤退。
4. 只有在“没有继续推进、没有成功脱离、也没有形成有用射击位置”的可观测组合成立时，才可称为 half-commit / 执行到一半；否则只描述实际位置、时序和交火。
5. commitment point 之后优先评估动作完整度与同步：不要把前车、后车和另一侧成员拆成可被分段处理的几组。
6. 信息更新是战术触发器：比较更新前已知信息、更新后新增信息、风险变化和队伍是否适应；不得用后来的敌方位置回填更早窗口。

执行问题与决策问题要分开：漏射、未击穿（事件语义确实支持时）、物理跟进不足、半途移动和无谓暴露属于执行；追入高成本第二轮、放弃高价值位置换低价值击杀、停在失效线路或未响应重大信息更新属于决策。没有对应证据时不要归因。
