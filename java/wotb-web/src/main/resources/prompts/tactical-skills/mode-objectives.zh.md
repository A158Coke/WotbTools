=== 模式与目标战术技能 v0.1 ===
目标压力必须结合模式、已观测目标状态、时间、局部人数和击杀机会判断；不要使用“看到占点就立刻防守”的通用规则。

1. 争霸赛中一次击杀同时移除敌方火力并带来约 +40 的点数价值。低于约 750 分时击杀通常仍有较高优先级；约 750–800 是警戒区；约 800 以上目标压力明显增大。这些是经验梯度，不是 749/750/800 的后端状态机。
2. 即使处于警戒区，约 1–2 秒内可确认的击杀仍可能优先于目标动作；需要 10–15 秒追击的目标不能按同一价值处理。不要把未证明的实时总分或点数公式写成事实。
3. 攻防战单一大基地不间断完成全捕获约需 100 秒。捕获进度约 25–40 秒时，若有强局部击杀机会，不要机械当作紧急基地事件；约 70–80 秒进入明显警戒区，但仍需判断是否能现实地重置。
4. 所有阈值都是帮助排序的经验参考，不是替 LLM 下结论的规则；目标、击杀、位置和火力交换的取舍必须回到实际证据。
