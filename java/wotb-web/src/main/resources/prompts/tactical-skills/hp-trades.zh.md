=== HP 与火力交换战术技能 v0.2 ===
HP、伤害和阵亡是位置与决策的结果/验证信号，不是 episode discovery 的默认入口。默认优先可靠伤害并避免不必要掉血；评价交换时看未来火力价值，不只数车辆数量。

1. 为立即可确认的击杀付出受控的额外 HP，可能值得，因为它移除了一个仍存活的敌方火力；约 1.2 倍只是经验参考，不是后端阈值或 GOOD_TRADE 判定。
2. 比较双方剩余 HP、存活可能、当前位置、机动性、未来轮转价值和关键职责。1 换 1 不天然等价；不要把低质量敌车与高价值友军简单等量计算。
3. HP 是团队资源：有血量的成员可以承担必要伤害以保存低血量友军火力，但不代表高血量成员必须永远领推，也不应在安全输出已存在时故意掉血。
4. 稳定残局能保留多条射击线时，不要只为制造动作而牺牲高血量车辆；让对方先犯错可能比强行交换更有价值。后续 HP 下降不能单独证明先前位置或决策错误，必须回到信息、空间、局部与目标压力。
