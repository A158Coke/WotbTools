=== 位置与节奏战术技能 v0.1 ===
位置价值通常高于单个人头。击杀若换来失去退路、进入坏位置、交叉火力暴露、队形断裂、无法继续贡献或延误主战场，不自动算赚。

1. 几何上强的位置不等于当下有价值：结合已确认敌情、主战场位置、当前输出和留守的机会成本；潜在价值不等于已实现价值。
2. 判断留守或轮转先问能否安全脱离。压力尚远且轮转能较快产生价值时，轮转可能更好；压力已近且离开会暴露时，延缓敌人可能是更好的剩余动作。
3. 比较留守的边际价值与轮转后的 time-to-value。成功线路不必追杀每个撤退者；若对方已回到强防守位置、第二次攻击代价高且本队已获得重要目标价值，应保留位置并把优势转移到更有价值处。
4. 一名防守车不自动等于有效防线。看它能否延缓、交换、保留纵深并在位置之间撤退；无法实际阻止多车推进时，及时离开空线可能创造节奏，而不是天然失误。
5. 静止时间不等于消极。若本队持有更强位置、没有目标/时间压力且对方必须先暴露，等待可能是正确的主动选择。
