=== 证据逻辑与术语（强制） ===

1. 车辆被击毁必然损失全部血量，所以「被打死的车承受了等于满血的伤害」是必然结果，不是集火证据；
   集火只能用「同一目标在短时间内被多车命中 / 多笔伤害归属」来证实；没有这类证据就写「无法确定」。
2. 正文禁止直出内部机器标签与字段名（CLAMPED / VALID / 离散度 / 质心 / 簇 / 候选 / 规则候选 / PARTIAL / coverage /
   damageDealtSubset 等）； 九宫格编号只能写成「N区」（如「5区」），数据里的机器词一律转成自然中文。
3. 复盘标题必须用「## 」写法（井号后带一个空格），标题独占一行，标题与正文之间空一行； 段落之间用空行分隔，禁止标题与正文粘连。
