# 游戏公告与历史版本

> Canonical language: Chinese; English translation pending.

游戏公告页面（`?view=game-announcements`）向未登录访客提供国际服最新官方更新公告和本站审核归档。莱斯塔显示“暂未开放”，不能进入，也不会采集。来源为 WG ASIA 门户的 updates 分类，更新、平衡、延期等文章由管理员判断是否归档。

## 来源与语言

最新列表及已读取正文每12小时刷新，失败保留最后成功内容并显示同步状态。首次读取未缓存正文会触发一次受控请求；后续访客共用缓存。缓存有容量上限，重启后重新预热；它不是永久归档。CMS接口变更或网络失败不清空本站历史快照。

2026-10-17核验的ASIA门户支持en/ja/ko，中文路径回退到英文。因此当前使用实际英文内容并如实标注。本站按钮和提示支持中文、英文、俄文；UI语言不改变文章真实语言。官方未附时区的发布时间保留原始文本，不推算UTC或国服时间。

## 审核与分类

新闻管理员（`news-admin`）或联赛管理员（`tournament-admin`）均可管理。最高管理员通过Keycloak复合角色继承；新闻角色不获得联赛管理权限。前后端都校验真实角色，开发可见性旁路不授予新闻权限。

管理员选择文章、逐块勾选并核对最终预览，填写版本、标题与分类后保存。标题、段落、图片、完整列表和表格是勾选单位；全选即全文，不能编辑原文文字。合并时可以调整文章顺序，每篇内部块顺序固定。分别归档允许各篇独立填写元数据；同一版本多篇、同一来源不同摘选均合法。

每次预览绑定内容revision；来源变化、缓存淘汰或块不匹配时要求重新预览。部分选择只影响本次归档，不改官方缓存。保存后冻结来源、正文与类别，重试、撤下、恢复均不能修改它们。

类别为动态通用/专用类型；最多一个专用类别、可附加多个通用类别，也可仅用通用类别。类型创建后不能改；归档保存后关联不能改。迁移一次性初始化“版本更新（通用）”“车辆平衡（专用）”“机制平衡（专用）”，不会在启动时补回已删除类别。任何状态的归档仍引用类别时都不能删除它。

## 发布与删除

保存产生准备中的归档。必要封面和选中正文图片全部备份至COS后才公开；没有图片可直接完成。图片失败时保留原审核快照，管理员可以重试或删除。未选内容的图不参与准备。

已发布记录可以撤下；撤下立即从公开列表、详情和新图片请求中隐藏，但保留内容和引用。恢复须检查自有图片完整，只重新公开原快照。永久删除必须先撤下；从未发布的失败记录可直接删，准备中的记录不能删。

同一次审核重试通过持久幂等键返回原结果，不重复保存；同键不同请求冲突。删除后旧请求仍不会重新创建记录。归档删除仅清理该条正文和关联，不影响同版本其他归档。图片在解除最后引用后经过24小时宽限再回收；失败保留元数据供重试，仍有任何引用不得回收。

已经下载到访客设备的内容无法撤回；“撤下”控制后续本站读取，不承诺清除设备上的副本。

## 实现与验证边界

- HTTP契约：`contracts/http/openapi.yaml`；公开 `/api/news/**`，管理 `/api/admin/news/**`，错误采用canonical ApiError。
- 后端owner：`java/wotb-web/.../news/`，持久快照与12h内存源缓存分离。前端owner：`useGameAnnouncements.ts`，transport集中在`api/game-announcements.ts`。
- 官方图库先展开再分块；HTML净化不执行原站脚本。官方源和图片下载限定受审origin/CDN，校验每次重定向、DNS目的地址、字节与耗时；不提供任意URL代理。
- COS上传前登记预约，上传与GC锁定同一图片行；任务过期使用attempt token隔离，迟到worker不能复活已删归档或已失管对象。
- Web/Android均从本站API读图；Android经`resolveApiUrl`映射生产API，不扩大CSP。
- 当前新闻图片支持PNG/JPEG/GIF（总字节、尺寸、解码和动画帧均受限）；不支持的格式明确失败，不能静默删除必要配图。直播图片规则保持PNG/JPEG。
- 单元/集成测试使用官方形状fixture、一次性PostgreSQL与mock COS；真实COS写读/回收、Android真机验收和生产发布是独立的上线步骤。

配置、权限和恢复见[公告图片运维](../operations/news-images.md)。
