# AI Lesson：cw-delay-no-payoff-01 — 无获利不硬判拖延

- **案例 id**：`cw-delay-no-payoff-01`
- **场景**：H2 单走静止（90–220s），但远离目标点、无敌情压力；队友全程原地未利用时间。
- **AI 常见误判**：看到「静止 + 单走」就判拖延。
- **正确判定（LLM 解释）**：**不硬判拖延**——Backend 只给中性测量（无目标点邻近/无敌情压力/队友窗口内活动为空）；是否拖延由 LLM 综合判断，证据不足时保持无法确定。
- **判定依据**：
  - 静止但无卡点/守点语义；
  - 无敌情压力；
  - 队友窗口内活动为空（未转场/未占点/未推进）——是观察事实，不是「队友未获利」判定。
- **对应 golden case**：`ai-eval/cases/cw-delay-no-payoff-01.json`
- **规则引用**：`SEPARATION_EVIDENCE_RULE`（Backend 只输出中性空间分离测量；拖延与否由 LLM 综合判断）。
