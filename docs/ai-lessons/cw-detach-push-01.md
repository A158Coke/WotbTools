# AI Lesson：cw-detach-push-01 — 单走推进被集火 = 脱节

- **案例 id**：`cw-detach-push-01`
- **场景**：MT（M1）开局后持续向敌区推进拉大距离（45–90s），远离目标点、被 3 车集火阵亡；队友原地未获利。
- **AI 常见误判**：把无收益的推进说成「拖延/拉扯」。
- **正确判定（LLM 解释）**：可判**脱节**（无拖延收益——队友窗口内活动为空 + 被集火/丢点）；由 LLM 综合 Backend 中性测量得出。
- **判定依据**：
  - 移动段持续移动且距离增大（`type=移动`）；
  - 远离目标点、无卡点行为；
  - 阵亡前承伤高、队友无转场/占点/推进关联。
- **对应 golden case**：`ai-eval/cases/cw-detach-push-01.json`
- **规则引用**：`SEPARATION_EVIDENCE_RULE`（脱节=无收益 + 被白吃/丢点，LLM 综合判断）。
