# Android 4.4.3

- versionName：4.4.3
- versionCode：4004003（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：patch（装甲查看器厚度/热力图：间隙甲同板去重与背面法线修复；在已合并的 4.4.2 之上顺延；不涉及解析契约、回放权威输入、WASM pin 与 Native 代码）
- 最低支持版本：保持 4.1.0 / 4001000，不因本版本抬升。

## 说明

- **间隙甲同板去重**：热力图厚度通道对开放网格（炮盾等）按 front/back clone 与
  去重键（原始 section + plate）写/测 stencil 位，每个像素对同一块板只累计一次厚度；
  闭合网格仍用 `FrontSide` 单次累计。去重键超过 8 位 stencil 容量时整车回退双面累计并
  `console.error`（fail-closed）。点击判定与热力图不再出现「开放壳体出射面被当第二块板
  双计」导致的热力图偏厚。
- **背面法线**：`BackSide` clone 在片元着色器中按 `#ifdef FLIP_SIDED` 翻回几何法线，
  修掉背面屏入射角取成 `π−θ` 造成的等效厚度爆炸（20mm 背面屏被算成 2e7mm → 全 blocked）。
- **深度纹理**：厚度 RT 的深度纹理由 `createDepthStencilTexture` 单点构造
  （`DepthStencilFormat` + `UnsignedInt248Type`），首建与 resize 重建同源；
  `stencilBuffer: true` 才会真正挂上 stencil 附件。
- **版本基线**：main 的 4.4.2 已由坦克百科默认排序占用（见 [4.4.2](4.4.2.md)）；本 PR
  后合，按 Version-as-Code 顺延到 4.4.3，该候选同时包含两批改动。
- Web bundle 随 APK 打包；Agent WASM pin 不变。发布说明在发布时归档。
