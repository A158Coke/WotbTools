## 说明

- Agent 正式 Release 由 v0.4.14 升到 v0.4.15，仍使用 commit-addressed 产物
  `/wasm/<ref>/`，未恢复 stable alias。
- 新增第五类 WASM capability `parseAuthorInitialPosition` 的 WotbTools 消费边界：
  `parseAgentAuthorInitialPositionFromBytes` 返回 `{ author_eid, clock, position }` 或
  `null`；validator fail closed，未知证据不会降级为 `[0,0,0]`。`position` 保持 Agent
  原始 replay 世界坐标 `[x, y, z]`（x/z 水平面，y elevation），本版本不做 WotbTools map
  转换或 spawn classification。
- `parseResult` 仍只读 meta + battle_results，不扫描 packet stream；新 probe 只有显式调用
  才执行。
- 本版本只接入 capability 与其消费边界，不包含 Battle Data Collector、Collector HTTP
  endpoint、数据库、arenaId dedupe、Random/Rating eligibility、Statistics UI 或自动上传。
