## 说明

- 射击结果卡在横屏手机/矮视口下改用紧凑字号并封顶 420px 宽，不再铺满屏幕。
- 装甲查看器普通检视换弹只清除上一次判定结果，不按旧位置自动重跑；
- 装甲查看器的击穿视图改为默认开启（`?heatmap=0` 显式关闭）。
- 装甲厚度与击穿视图互斥；厚度模式点击只在右上角面板内显示该板的**基础装甲值**
  （不再浮出部件名/入射角/等效厚度卡片，也不遮挡车体），并显示炮管/履带碰撞体（纯色无贴图）；
  主装甲/间隙装甲/外部模块的隐藏开关放在同一面板的模式按钮下方，只在装甲厚度模式下出现；
  模式按钮文案固定，切换时面板不跳动。
- 装甲厚度模式点击某块装甲板后高亮该板（保持不透明、不改厚度色相），其余装甲板/模块降透明度，
  对齐 BlitzKit 的装甲检视观感；再点其它板高亮随之移动，点空处/退出厚度视图/换配置/过滤
  隐藏该板即复位。
- 修复装甲查看器**视觉模型**缺件：`gun_XX_mask`（炮盾/炮根视觉）不再被外部模块选取规则
  隐藏——Super Conqueror（19281）等无 mask 值的车，炮塔与炮管之间只由该网格连接，旧规则
  让带贴图的炮管断开。裁定/厚度视图仍按客户端口径只用炮管部分（见下条）。
- 装甲查看器炮管裁切保持 BlitzKit 口径：按 `gun_mask` 标量 + 模型原点链建裁切面，随炮塔/
  炮管姿态重算，贯穿点击/跳弹续飞/热力图/厚度视图；有 mask 值并入 `gun_0X` + `gun_0X_mask`
  网格并由平面裁掉炮根，无 mask 值只判精确 `gun_0X`；视觉模型仍渲染完整炮管。此前按客户端
  完整 maskSlice 记录原值建面的方案经实测不一致（多数车平面落在炮管外/中段，部分车会切掉
  大半根炮管），已回退；资产包 sidecar 保留但不被 viewer 使用。
- 间隙甲改为**双面**（与点击判定同口径）：击穿判定的点击主链/跳弹续飞接受背面命中的
  间隙屏（同一块板只计一层）；热力图的间隙甲着色/状态材质与深度占位、装甲厚度视图的
  间隙甲实心材质都改为 `DoubleSide`，片元着色器按 `gl_FrontFacing` 翻转法线，从背面看
  也能看到并正确判定间隙屏。
- 装甲查看器改为 BlitzKit 式布局：右上角是**一块固定宽度的整体面板**——弹种图标 + 校准弹/强化装甲
  装备图标（两个开关在装甲检视与击穿概率模式下都即时生效）、厚度/热力图模式切换、装甲组成开关与
  点选结果共用同一张卡片，不再堆叠多张浮层；进入厚度模式出现过滤行/点选结果时面板宽度不变；「参数」
  面板里射击方/受击方各一张卡：卡头整合坦克切换与模块选择，模块区默认收起；只保留模块
  （装备/消耗品/技能不在装甲页）。
- 射击复现页的装配只保留与射击相关的五项并图形化：射击方主炮/校准弹/弹种、受击方炮塔×炮/
  强化装甲（图标格与开关，换配置就地生效，不重建 3D 场景）。
- 科技树成为与坦克百科平级的主导航栏目（侧边栏/底部栏独立项，顶栏标题为「科技树」），
  侧栏导航图标放大；科技树页的「坦克百科」按钮补上坦克百科图标。
- 修复连发炮（PomPom，如 AC Atlas / ATAC）的 DPM：整夹内「组内连发」与「组间扳机间隔」
  分开计（BK `resolveDpm` 同式），旧算法把组内弹间也按组间间隔放大。依赖资产包新增的
  `tank/{id}.json` `configs[].burst_group_count/burst_group_interval`（两包已更新并重算 manifest）。
- 火力参数对连发炮新增三行客户端同名参数：连发组数、每组发数、组内连发间隔；
  整夹只有一组连发（如 Annihilator 的 Cerberus）时不再显示无意义的「弹间装填」。
- 新增科技树页（`?view=agent-techtree`）：九国车辆树按客户端原始 x/y 网格渲染（216×96
  单元格语义）；研发连线按客户端 Lines{linesMask} 图案几何路由（上游从客户端 UI yaml
  提取的常量：出线源格右侧 20px、跨行干线骑列边界、入线目标格内 13px + 箭头）；等级条
  为客户端 LevelCell 语义（罗马数字、吸底随内容横滚、窗口 minLevel..maxLevel，XI=11 列）；
  金币/收藏车只由卡片边框区分（金 = premium、蓝 = collector，与选车菜单同口径），不画
  顶部金币车带、不出逐车「高级」徽标；单元格归属由客户端模型重排、数据不可证，不重排任何格子。直接容纳 11.22 超测 XI 预览车（BZ-79 / Object 432U，`preview: true`），
  6 个已登记未实装位渲染为无名称占位（不造数据）。数据 = 资产包 `research/tech_tree/**`
  （上游 `--with-research-graph` 导出；旧资产包无该文件时页面显式报错，可重试）。
- 科技树节点点击直接进入坦克百科详情；详情页头部的「研发」按钮打开单车研发弹窗（复刻客户端
  ModulesTree，与配置栏模块矩阵共用同一 URL 选择态）：上一辆/下一辆车由科技树边反解，
  模块研发图为确定性推导布局（列=最长入边深度、行=模块族，页面标注「布局为复刻推导」），
  节点状态只有 installed（当前搭载对号）与解锁成本（XP，多父取最小）；XI 超测车无研发链
  （客户端数据零解锁边）时显示数据注记；不做研发/购买/解锁流程（2026-10-27 裁定维持）。
- 装备/消耗品/模块 UI 接入：坦克百科 → 装甲查看器 URL 携带 `dev/cons/prov`，装甲查看器
  「参数」面板新增「实际搭载」区（懒加载，首次展开才拉 research 数据）；射击复现详情显示
  该弹射手 Type5 配件串徽标（`shooter_equipment.raw` → devices.json 图标，未知 id 走
  通用未知文案）；战斗回放车辆卡装备芯片叠加客户端图标并新增「在配置器中打开」
  （`?tank=&eq=` → 配置器反解槽位，歧义 fail-closed 留空）。
- 配置器面板手机（<768px）模块矩阵折 2 列（列语义对齐保持）、触控目标放大。
- 坦克百科 query 键新增 `eq`（回放装配 id 一次性透传，反解后从 URL 移除）。
