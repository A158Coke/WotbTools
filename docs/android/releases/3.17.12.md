## 说明

### 上游 / WASM

- Agent 正式 Release 由 v0.4.14 升到 v0.4.15，仍使用 commit-addressed 产物
  `/wasm/<ref>/`，未恢复 stable alias。
- 新增第五类 WASM capability `parseAuthorInitialPosition` 的 WotbTools 消费边界：
  `parseAgentAuthorInitialPositionFromBytes` 返回 `{ author_eid, clock, position }` 或
  `null`；validator fail closed，未知证据不会降级为 `[0,0,0]`。`position` 保持 Agent
  原始 replay 世界坐标 `[x, y, z]`（x/z 水平面，y elevation），本版本不做 WotbTools map
  转换或 spawn classification。
- `parseResult` 仍只读 meta + battle_results，不扫描 packet stream；新 probe 只有显式调用
  才执行。
- 本版本只接入 capability 与其消费边界，不包含 Battle Data Collector、Collector HTTP
  endpoint、数据库、arenaId dedupe、Random/Rating eligibility、Statistics UI 或自动上传。

### 前端 / 坦克百科

- 射击结果卡在横屏手机/矮视口下改用紧凑字号并封顶 420px 宽，不再铺满屏幕。
- 装甲查看器普通检视换弹只清除上一次判定结果，不按旧位置自动重跑；
- 装甲查看器的击穿视图改为默认开启（`?heatmap=0` 显式关闭）。
- 装甲厚度与击穿视图互斥；厚度模式点击以**命中点旁侧的浮层**显示该板的**部件名称与基础装甲值**
  （浮层相对点击坐标偏移 + 视口钳制，不盖住命中点；入射角/等效厚度/穿深/结果不显示），
  并显示炮管/履带碰撞体（纯色无贴图）；主装甲/间隙装甲/外部模块的隐藏开关放在同一面板的
  模式按钮下方，只在装甲厚度模式下出现；模式按钮文案固定，切换时面板不跳动。
- 装甲厚度模式点击某块装甲板后高亮该板（保持不透明、不改厚度色相），其余装甲板/模块降透明度，
  对齐 BlitzKit 的装甲检视观感；再点其它板高亮随之移动，点空处/退出厚度视图/换配置/过滤
  隐藏该板即复位。
- 修复装甲查看器**视觉模型**缺件：`gun_XX_mask`（炮盾/炮根视觉）不再被外部模块选取规则
  隐藏——Super Conqueror（19281）等无 mask 值的车，炮塔与炮管之间只由该网格连接，旧规则
  让带贴图的炮管断开。裁定/厚度视图仍按客户端口径只用炮管部分（见下条）。
- 装甲查看器炮管裁切保持 BlitzKit 口径：按 `gun_mask` 标量在枪管局部系建面（BlitzKit
  同式），再乘炮塔/炮管姿态矩阵（绕 models.pb 枢轴）与模型根变换进世界系——姿态变化时
  平面随枪管绕枢轴旋转，贯穿点击/跳弹续飞/热力图/厚度视图；有 mask 值并入 `gun_0X*`
  全部网格（含 `gun_0X_mask`/辅助件）并由平面裁掉炮根，无 mask 值只判精确 `gun_0X`；
  视觉模型仍渲染完整炮管。此前按客户端完整 maskSlice 记录原值建面的方案经实测不一致
  （多数车平面落在炮管外/中段，部分车会切掉大半根炮管），已回退；资产包 sidecar 保留但
  不被 viewer 使用。
- 间隙甲按几何拓扑选面：开放面片用 `DoubleSide`（背面命中仍可见），闭合网格用
  `FrontSide`（additive 着色每个像素只累计最近正面一次，正/背两表面不重复计厚）；
  深度占位与装甲厚度视图的间隙甲实心材质保持 `DoubleSide`，片元着色器按
  `gl_FrontFacing` 翻转法线。击穿判定的点击主链/跳弹续飞仍接受背面命中的间隙屏

- 修复履带上表面在装甲视图里“位置不对/缺一块”：模块替换材质（厚度视图实心色、热力图
  外部模块的深度/着色/状态 clone）沿用源 GLB 材质的 `side`；客户端履带是双面材质且上表面
  绕序朝内，旧实现固定 `FrontSide` 会把上表面剔除（轮子等单面模块不受影响）。
- 装甲查看器改为 BlitzKit 式布局：右上角是**一块固定宽度的整体面板**——弹种图标 + 校准弹/强化装甲

  面板里射击方/受击方各一张卡：卡头整合坦克切换与模块选择，模块区默认收起；只保留模块
