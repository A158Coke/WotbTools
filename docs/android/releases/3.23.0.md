# Android 3.23.0

- versionName：3.23.0
- versionCode：3023000（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：minor（新增 3D 回放录像者视角；Agent WASM pin 升级到 v0.4.21，随 web bundle 进 APK）
- 最低支持版本：保持现有发布配置，不因本版本抬升。

## 说明

- **录像者视角**：3D 回放可用录像者本人的瞄准方向、开镜时机和缩放重看战斗，开镜时进入炮位狙击视角。
- **准星**：中心点表示瞄准方向，扩散圆跟随炮管实际指向；圆的绝对尺寸是校准值。
- **相机入口**：模式为自由 / 沙盘 / 录像者，沙盘即持续的总览模式；旁边的「俯视」按钮一次性回到俯视机位，之后是自由视角。
- **可用条件**：录像者存活且回放通过协议校验；阵亡后回到自由视角，seek 回去可重新进入。
