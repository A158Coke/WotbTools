# Android 3.28.2

- versionName：3.28.2
- versionCode：3028002（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：patch（修复 3D 回放战斗反馈）
- 最低支持版本：保持现有发布配置，不因本版本抬升。

## 说明

- **伤害数字**：3D 回放的伤害数字不再受「车辆状态标记」开关影响，一键防遮下也会显示，只有隐藏全部 UI 才隐藏。
- **损失血量残影**：3D 回放受击时血条立即到新值，刚损失的区间显示为暗色段，短暂停留后淡出。连续受击时延伸同一段，隐藏 UI 或车辆出屏后恢复时继续淡出，不从头重播。
- **显示选项文案**：3D 的状态标记选项改为「车辆状态标记」，一键防遮提示同步说明伤害数字。
- **2D 回放**：损失血量残影改为同样的暗色段，连续受击时重新开始淡出。
