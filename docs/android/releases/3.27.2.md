# Android 3.27.2

- versionName：3.27.2
- versionCode：3027002（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：patch（地图预览：基地点位直显 + 封面统一 + 底图升级 + 标注互导）
- 最低支持版本：保持现有发布配置，不因本版本抬升。

## 说明

- **基地点位直接进 2D/3D**：地图预览的 2D/3D 视图直接叠加基地点位（无独立面板）——3D 为
  回放同一条贴地管线（贴地环 + 随相机转正的圆盘贴图），2D 为同一 BattleMap 圆标口径；
  头部「争霸/遭遇」切换，URL `?bases=` 持久化。仅打包注册表收录的 29 张有几何（客户端
  `.sc2` 提取），未收录图不显示、不显示切换；遭遇选项只在 assault 组恰好 1 个候选时
  提供（攻防/遭遇条目无法归属的多候选图不给必空选项），与渲染端 fail-closed 同判据。
- **封面统一 cover.webp**：地图预览选图网格的封面此前来源不一——29 张为打包战术底图，
  14 张未收录图回退 `ground.webp`（4096²、3–4MB/张）。现全部 43 张统一为 `cover.webp`
  （512²，与 2D 战术底图同一调色管线，~100KB/张）：选图网格流量 42MB → ~1.5MB，
  来源与风格一致。
- **未收录图 2D 底图升级**：那 14 张图的 2D 模式底图从 `ground.webp`（4096²、3MB）换成
  `map2d/<key>.webp`（canonical 1254² 校准战术图，~900KB，worldBounds ±300 契约框）——
  加载提速，风格与另外 29 张一致。
- **标注导入导出跨视角**：导出文件不再区分 2D/3D（同一张地图即可互导），合入前旧导出
  （`-2d`/`-3d` 后缀）仍可导入。
- **不变的部分**：回放工作台五能力、地图预览的 3D 场景与绘制功能、装甲查看器与录像者视角
  的行为与之前相同。
