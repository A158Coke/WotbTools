# Android 3.0.3

- versionName: 3.0.3
- versionCode: 3000003
- Native Bridge: v3 (unchanged)
- Version classification: patch — fix the two GeckoView runtime blockers that break web blob downloads and could leak a response body stream.
- Minimum supported version: 3000000. Same-major patch publication does not raise the floor.

GeckoView dispatches a download through `NavigationDelegate.onLoadRequest` **before**
`ContentDelegate.onExternalResponse` ever sees it. The previous main-frame rule (exact local origin or
`about:blank`, everything else denied) therefore denied every `blob:` URL, so `<a download>` exports —
网页 PNG 导出、HoF replay 下载、tournament XLSX — never reached the download pipeline. Main-frame
navigation now also allows `blob:http://127.0.0.1:21653/<uuid>`: scheme `blob`, and the embedded URL must
be the exact local origin (same scheme, host and port, no userinfo / query / fragment) followed by one
canonical UUID — the spec shape of `URL.createObjectURL`. Nothing else changed: external `https:` / `mailto:`
still go to the system browser, all other
schemes and malformed blob URLs are still denied, subframes still accept only the local origin, and the
blob URL is only a download-dispatch exception — it is never treated as an application origin, so the
Native Bridge sender check still accepts only the exact `http://127.0.0.1:21653` origin.

`LocalRuntimeServer` now owns the `StreamResponse.data` lifetime end to end: the body is closed exactly
once on every path (HEAD, output-stream open failure, header write failure, body copy failure, flush
failure, client disconnect, unexpected exception). The previous `data?.use { body.copyTo(...) }` only
covered the copy, so a failure while writing the response head — or a `getOutputStream()` failure after
the route had already opened a replay / folder / asset / proxy-cache stream — leaked the file descriptor.

Real-device acceptance must cover the blob export and download checklist in
`docs/android/release-process.md`; CI cannot exercise the GeckoView download dispatch itself.
