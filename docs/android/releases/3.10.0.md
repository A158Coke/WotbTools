# Android 3.10.0

- versionName: 3.10.0
- versionCode: 3010000
- Native Bridge: v3, unchanged
- Version classification: minor — share the Tankopedia's tank catalog menu with the armor viewer (fuzzy search with aliases, tier/nation/type filters, name/tier/hp/pen sort, compact chips plus filter sheet, shared cards and incremental loading) and fix the armor viewer's kinetic-shell penetration semantics for external modules (first-actual-armor normalization / 2×-caliber enhanced normalization).
- Minimum supported version: unchanged at the existing 3.0.0 major floor; this optional feature and bug fix do not require a forced update.

The armor viewer's target/shooter picker now uses the same `TankCatalogMenu` as the Tankopedia: fuzzy search with search aliases, tier/nation/type filters, name/tier/hp/pen sort, compact chips plus filter sheet, shared cards and incremental loading. The list stays mounted across Tankopedia detail navigation, preserving the expanded page and the in-flight search draft. Only the dialog shell and the viewer selection callbacks remain page-specific.

External modules (tracks, gun barrel) are flat consumables for the first-actual-armor-layer rule: a kinetic shell that penetrates a module still cannot ricochet, but the first real armor layer behind it keeps its normalization and 2×-caliber enhanced normalization. The click judgment, heatmap and ricochet continuation share the rule; the 3×-caliber `overmatch` flag now reports only the actual caliber rule, and the heatmap keeps the nearest spaced plate's normalization delta when a module is in front.

This bundled UI minor release follows main's 3.9.0 candidate (3D playback toolbar collapse) and supersedes the earlier unmerged 3.9.1/3.8.2 armor candidates. Staging, real-device acceptance and production publication remain separate release steps; this document does not assert they have completed.
