# Android 3.10.0

- versionName: 3.10.0
- versionCode: 3010000
- Native Bridge: v3, unchanged
- Version classification: minor — configurable Chinese/English/Russian league season names and numeric points-group labels, exposed through versioned v2 catalogue endpoints.
- Minimum supported version: unchanged at 3000000. Existing APKs continue using the original response shapes and administration endpoints; no forced update is required.

The season list, breadcrumbs, dialogs and deletion prompts display the configured name for the selected language; Russian falls back to English when absent. Replay titles and team names remain the source text. Points groups use a positive integer and fixed Chinese/English/Russian labels, independently of the knockout groups' 1–4 cap. Non-numeric legacy group labels are retained for manual correction.

Original catalogue endpoints keep the previous single-name and groupLabel wire shapes, including rejecting extra response fields in old APK validators. The updated bundled frontend uses v2 endpoints against the same services and stored records. Backend rollout can precede APK publication without invalidating old clients; new names and numeric labels become available when users update.

Existing names are retained in both required fields during migration. Only source-backed individual matches with confirmed dates, teams and stages enter the seed. This source candidate does not establish staging, device acceptance or production publication.
