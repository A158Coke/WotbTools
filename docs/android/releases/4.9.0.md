# Android 4.9.0

- versionName：4.9.0
- versionCode：4009000（由 wotbVersion 推导）
- Native Bridge：v3（不变）
- 类型：minor（坦克百科 XI 车辆研发界面：升级树复刻；继 4.8.1 之后）
- 最低支持版本：保持现有门槛，不抬升。

## 用户可见行为

坦克百科 XI 车辆（超测通道）详情页「研发」按钮改为打开升级研发树（客户端
TankProgress/UpgradeProgression 复刻）：96px 格网上按 gridPosition 渲染增强节点，
连线沿 requiredNodes 布线并带到达方向箭头；增强组为右侧三选一环扇。单击未研发
节点即研发（连带全部前置），单击已研发节点回退其下游分支（组级联卸载并清除
三选一标记）。每个节点显示属性增量（引擎被击中起火几率等按 % 口径，其余按
客户端原始增量），机制属性配客户端同版描述。数据来自资产包
research/modules/{nation}.json 的 upgradeProgression（上游 2026-11-08 布局字段）。

Web 前端随 APK 打包；HTTP、资产格式与 Native Bridge 不变。3D GPU 观感和
Android 真机体验由人工验收。
