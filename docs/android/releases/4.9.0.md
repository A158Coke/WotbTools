# Android 4.9.0

- versionName：4.9.0
- versionCode：4009000（由 `wotbVersion` 推导）
- Native Bridge：v3（不变；新增可选能力 `screen-form`、`haptics`，旧 App 没有能力时 Web 静默降级）
- 类型：minor（WotbTools 4.0 界面改版）
- Minimum supported version：raised to 4009000 (4.9.0)。用户指令例外：4.0 界面与导航整体改版，用户要求一次性把全部用户更新到新界面（见 `release-process.md`「用户指令例外」）。合并前需先把仓库变量 `ANDROID_MIN_SUPPORTED_VERSION_CODE` 设为 4009000。

## 用户可见行为

- 手机导航改为左侧抽屉，底部 Tab 退役；普通页面向下滚动时顶栏收起，工作台不收起。
- 四季主题：春 · 青山、夏 · 盛夏（默认）、秋 · 金秋（深色），冬 · 寒冬（浅色）；旧主题设置自动映射到盛夏。
- 2D / 3D 回放、地图 3D 与装甲查看器在手机上强制横屏，并提供横屏沉浸菜单；装甲判定结果固定在顶部中间。
- 统一反馈：toast、本机通知中心、按钮加载 / 完成状态，按键震动（默认开，可在「更多与设置」关闭）与可选按键音效。
- 名人堂、坦克百科、联赛积分榜、赞助、下载、账户页使用主题主视觉页头；「更多」改名「更多与设置」，管理入口只在抽屉的「管理」分组显示。

Web 前端随 APK 打包。强制横屏、触感、3D GPU 画面与 Android 真机体验仍需人工验收。
