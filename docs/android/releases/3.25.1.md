## 说明

- 3.25.0 的地图预览里，未收录打包 2D 底图的 14 张图（矿井阵地、变体空间、老版
  复刻等）封面回退用的是 `map/<key>/ground.webp`（4096²、3–4MB/张）——打开选图
  网格要拉约 42MB。改用资产包自带的 HUD 小地图 `mini.webp`（512²、44–112KB，
  43/43 全有）：打开选图网格的封面流量从 ~42MB 降到 ~1.5MB。
- 2D 模式底图不变：bundled 图仍用打包 webp（离线），回退图仍用 `ground.webp`
  全分辨率（那是 ±300m 契约框的坐标系职责，非封面）。
