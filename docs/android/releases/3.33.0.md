# Android 3.33.0

- versionName：3.33.0
- versionCode：3033000（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：minor（3D 绘制支持桥面/屋顶等可选表面）
- 最低支持版本：3017007（沿用当前生产门槛，不变）。

## 说明

- **3D 绘制按表面锚定**：3D 标注笔迹在桥面、屋顶等可绘制静态场景表面上绘制时停留在该表面层；
  同 XZ 的下层地形不再被误投影。纯地形笔迹保持既有贴地行为。
- **交互与生命周期**：pointer 取最近的 terrain / 可绘制 scenery 表面；commit、undo/redo、eraser
  断段与 terrain LOD 重建都保留可选 `surfaceY` 锚点；Map Preview 3D 的标注导出文件不包含该
  session-local 字段。
- **不变的部分**：Native Bridge 保持 v3；最低支持门槛不抬升；2D 标注、回放协议与既有地形
  绘制语义不变。
