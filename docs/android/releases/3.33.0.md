# Android 3.33.0

- versionName：3.33.0
- versionCode：3033000（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：minor（地图页默认只列已登记中文名的地图）
- 最低支持版本：3017007（沿用当前生产门槛，不变）。

## 说明

- **默认地图目录**：地图页默认只显示已在 `common/map_names.json` 登记中文名的地图；没有中文名的资产条目默认隐藏，不再把资产包清单整份铺开。
- **显示全部地图**：地图页页头新增开关，打开后显示资产包按 key 去重后的全部地图；开关只作用于当前页面会话，不写 URL、不持久化。
- **新增 5 张地图中文名**：米德尔博格 2014版（`erlenberg_old`）、王朝的珍珠（`grossberg`）、永恒冻土（`iceworld`）、寂静星海（`moon`）、沙漠之心2014版（`savanna_old`）。
- **深链兼容**：默认隐藏的地图仍可用 `?view=map-preview&map=<key>&mode=2d|3d` 直接打开；返回地图页后仍按默认目录过滤。
- **Native Bridge 与门槛不变**：Bridge 仍为 v3；本次为 minor，最低支持版本保持 3017007，不要求旧客户端强制更新。
