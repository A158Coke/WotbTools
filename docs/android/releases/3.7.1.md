# Android 3.7.1

- versionName: 3.7.1
- versionCode: 3007001
- Native Bridge: v3, unchanged
- Version classification: patch — replace existing broadcast server emblems with the approved local globe illustrations.
- Minimum supported version: unchanged at 3000000 (3.0.0 floor); this visual correction does not require a forced update.

The five region emblems show China, Asia-Pacific, the Americas, Europe and the Russia-focused Lesta view. Globes scale to the available upper card area while retaining the existing card grid, heights and bottom labels. The Asia card displays APAC in its code and English name; the stored server key and deep links remain ASIA. Routing, availability and administration behavior remain the same. SVG assets are bundled for both Web and the local Android frontend.

The previous 3.7.0 candidate has an immutable tag, so the updated bundled assets use 3.7.1. Staging, real-device acceptance and production publication remain separate release steps.
