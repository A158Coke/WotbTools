## 说明

- **同板去重判据统一**：点击判定链（`collectJudgmentHits`）与热力图厚度通道共用
  `resolveSpacedHitMask`（`armorMeshTopology`）——同键按整条射线的命中集合判定：有入射面
  命中时出射面全部抑制，无入射面命中时出射面全部计入。`front→back`、`back→front`、
  `back→back` 三种穿越顺序得到同一层数；修复前 `back→front`（近背远正）会多计一层、
  同键仅背面会少计一层，点击卡与热力图因此不一致。
- **判定区间与 HE 首触面**：同板去重只在有效判定区间内生效——止于首个 Primary（判定链
  在其后截断，GPU 侧主装甲深度先写、远处 spaced 片元 depthTest 失败也写不了位）；区间外
  的同键入射面不会删除面前的间隙甲层。HE 的爆炸点取去重前的首个物理接触面
  （`firstPhysicalHit`），厚度累计去重不改变「碰到第一层表面即爆炸」的语义；HEAT 的
  间隙衰减以同一首触面为间距原点（`withGapOrigin`；与首层重合的命中一起搬，重合三角形仍合并），
  近背远正的空心壳不再少算内部行程；动能弹（AP/APCR）的首层跳弹判定同样按首触面几何（`withContactRicochet` /
  `ricochetSurface`）：厚度链的 normal/thickness/point 不变，首触面的法线/点位/厚度
  （含 3× 口径规则）单独随首层传递，只用于跳弹判定与续飞发射面（3× 口径按首触板厚度并先乘装备系数；外部模块首层同样
  承载首触跳弹；续飞链先过滤发射面近零命中再附加首触面）。GPU 厚度通道与状态通道
  因此各走各的口径，不再互相污染；跳弹层的结果卡按首触板名字/厚度呈现（`contact_part_name`/`contact_thickness`）。
- **回归门禁**：`test:browser-armor-spaced-backside` 增加反绕序开放壳（近 Back / 远 Front）
  与同键仅背面两个 GPU readback 场景；`armorMeshTopology` 单测锁定去重掩码的三种顺序、
  判定区间窗口（`back → Primary → 同键 front`）与 `firstPhysicalHit` 的首触面规则。
- **XI 默认顶级**：详情页、装甲查看器与射手侧缺省采用顶级配置；显式 `upgrade=stock` 仍可回退基础值。
- **卡片顶级血量**：坦克卡片优先使用上游资产 `tank_cache.hp_top`，普通车辆继续使用 `hp`。
- 旧资产包没有 `upgradeProgression` 时保持原始数据，不把旧包打成不可用。
- Web bundle 随 APK 打包；Agent WASM pin 不变。发布说明在发布时归档。
