# Android 2.4.0

- versionName: 2.4.0
- versionCode: 2004000
- Native Bridge: v2 (unchanged)
- Minimum supported version: unchanged at 2003000 (2.3.0).
- Version classification: minor — small feature inside the bundled frontend (account page shows more identity details); no HTTP or Native Bridge wire changes, no feature removal.

The account page's identity card now shows the Keycloak user ID (with a copy button) and the user's realm roles. Roles come from the access token's `realm_access.roles`; Keycloak built-ins (`default-roles-*`, `offline_access`, `uma_authorization`) are hidden and business roles are shown by their raw key. Groups are not shown: the realm defines none and the token carries no group claim.

This candidate builds on Android 2.3.8. The frontend is bundled inside APK assets, so the account page change requires a new committed source version. This document records the candidate scope; staging, APK real-device acceptance and production publication remain separate release steps.
