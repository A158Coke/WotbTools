# Android 3.0.1

- versionName: 3.0.1
- versionCode: 3000001
- Native Bridge: v3 (unchanged)
- Version classification: patch — targeted fixes to Gecko downloads and prompt lifecycle; the 3.0 runtime migration remains in the 3.0.0 release notes.
- Minimum supported version: 3000000. When publishing from a 2.x production version, retain the unpublished 3.0 major cutover obligation and raise `ANDROID_MIN_SUPPORTED_VERSION_CODE` to 3000000.

Web downloads and exports, including PNG blobs and Hall of Fame replays, now consume Gecko's response body into a private temporary file and use the Android document save picker. Cancelled and failed saves clean up the temporary file. Filenames honor Content-Disposition and MIME metadata.

Page navigation dismisses select and file prompts with exactly one result. Late Android file picker results are ignored rather than delivered to an old or replacement page prompt.

Before publication, perform the Gecko real-device acceptance in `docs/android/release-process.md`, including blob export, replay download, save cancellation, and navigation while select or file prompts are open. This document does not claim staging, device acceptance or publication has completed.
