# Android 4.4.1

- versionName：4.4.1
- versionCode：4004001（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：minor（资产数据版本通道的原生透传；不涉及解析契约、回放权威输入与 WASM pin）
- 最低支持版本：保持 4.1.0 / 4001000，不因本版本抬升。

## 说明

- **dataset 透传**：`AgentAssetProxy` 支持 `/agent-assets/v/<dataset-id>/...` 原样透传到远端
  资产 origin 的版本化 dataset 路径，与 Web 端「数据版本」选择器同批。
- **默认行为不变**：未指定 dataset 时仍走根路径 = origin 默认 dataset。默认通道是正式服
  `11.21.0`；超测服 `supertest` 是显式选择的预览通道，不进入默认路径。
- **缓存隔离**：不同 dataset 的磁盘缓存 key 含完整请求路径，天然按 dataset 隔离。
- Web 同批能力（侧边栏数据版本下拉）随前端镜像发布；`/versions.json` 与
  `/v/<id>/...` 由 asset-origin Caddy 提供。
- Web bundle 随 APK 打包；Agent WASM pin 不变。发布说明在发布时归档。
