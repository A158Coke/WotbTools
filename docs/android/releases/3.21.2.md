# Android 3.21.2

- versionName：3.21.2
- versionCode：3021002（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：patch（3D 场景相机行为变化，随 web bundle 进 APK）
- 最低支持版本：保持现有发布配置，不因本版本抬升。

## 说明

- **相机档位**：3D 回放模式改为 `自由 / 录像者`，并提供一次性的 `俯视` 按钮；默认以俯视机位进入自由。紧凑控制条下这些控件仍在「显示」面板。
- **俯视**：恢复为一次性动作，完成后仍是自由视角，WASD 立即可用；不再绕地图中心环绕。
- **跟随**：移除档位按钮，由点击车辆或名单触发；点 `自由` 或 `俯视` 退出，换回放时回到俯视机位的自由视角。
- **录像者**：按钮暂时禁用，数据接入后启用。
