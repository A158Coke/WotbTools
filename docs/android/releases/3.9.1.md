# Android 3.9.1

- versionName: 3.9.1
- versionCode: 3009001
- Native Bridge: v3, unchanged
- Version classification: patch — fixes lower-tier replay vehicle names and polishes the existing public tournament standings; no new business workflow or protocol change.
- Minimum supported version: unchanged at 3000000 (3.0.0); no forced update for this patch.

This candidate builds on 3.9.0 and retains its 3D playback toolbar collapse/expand feature.

The bundled vehicle reference library now loads all tiers 1–10. Replay data and exports resolve
lower-tier vehicle names and basic metadata. Item/equipment modeling keeps its reviewed 7–10 scope.
The server-side AI prose matcher ignores coordinate-shaped and ambiguous common-word vehicle
names, including Outcast, preserving ordinary prose and player references. Vehicle ID and roster
name lookup remain complete.

The public standings show a season title panel with the current board's clan count and published match-day count. Both values come from the already loaded standings; they add no requests or database reads. Two-level round headers use understated accent underlines, with clearer total scores and row separation.

Official rank values, row order, daily points, round totals and zero-versus-missing values remain unchanged. There are no additional tie labels, podiums or highest-score statistics. Event selection, source attribution, refresh and exports retain their existing behavior; administrator tables keep their default presentation. Showcase and Classic share the same implementation.

This source candidate does not establish APK staging, device acceptance or publication. Existing immutable identity and release guards apply.
