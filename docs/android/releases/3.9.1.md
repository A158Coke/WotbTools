# Android 3.9.1

- versionName: 3.9.1
- versionCode: 3009001
- Native Bridge: v3, unchanged
- Version classification: patch — fills missing localized search names in the existing Tankopedia
  alias dataset and corrects name recall/relevance in the existing search. These are small
  localization and search bug fixes, with no new search surface.
- Minimum supported version: unchanged at the existing 3.0.0 major floor; no forced update.

The bundled frontend includes 552 reviewed national-server short/full names plus one Latin-T
keyboard spelling for 471 vehicles in `common/tank_aliases.json`. For example, searching `鼠式` finds Maus and `45t战车` finds Carro 45t.
The official `T-34*` alias remains attached to Type T-34; a literal `*` query distinguishes it
from T-34 and T34. Unstarred queries retain Chinese recall for Mk I* Heavy Tank, exact canonical
names precede fuzzy aliases, and T-22 accepts both its official Cyrillic-T and Latin-T spelling.
Canonical displayed names remain English. Vehicles without a verified name keep their existing
search behavior. The Web frontend consumes the same dataset. Source provenance and update rules
are recorded in `docs/architecture/tankopedia-reference-data.md`.

This patch follows main's 3.9.0 candidate and preserves its accumulated features, including
the 3D replay toolbar collapse/expand controls. Native Bridge and the minimum supported floor
remain unchanged.

APK staging, device acceptance and production publication remain separate steps; this document
does not assert that 3.9.1 has been staged or published.
