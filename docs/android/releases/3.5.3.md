# Android 3.5.3

- versionName: 3.5.3
- versionCode: 3005003
- Native Bridge: v3, unchanged
- Version classification: patch — fills missing localized search names in the existing Tankopedia
  alias dataset. This is a small search-data correction, with no new search functionality.
- Minimum supported version: unchanged at the existing 3.0.0 major floor; no forced update.

The bundled frontend includes 551 reviewed national-server short/full names for 470 vehicles in
`common/tank_aliases.json`. For example, searching `鼠式` finds Maus and `45t战车` finds Carro 45t.
Canonical displayed names remain English. Vehicles without a verified name keep their existing
search behavior. The Web frontend consumes the same dataset. Source provenance and update rules
are recorded in `docs/architecture/tankopedia-reference-data.md`.

This candidate also includes the 3.5.2 Android file-picker cache fixes from main.

APK staging, device acceptance and production publication remain separate steps; this document
does not assert that 3.5.3 has been staged or published.
