# Android 3.5.3

- versionName: 3.5.3
- versionCode: 3005003
- Native Bridge: v3, unchanged
- Version classification: patch — improve the existing league broadcast server cards with Lucide icons, region codes, tinted backgrounds and responsive sizing.
- Minimum supported version: unchanged at 3000000 (3.0.0 floor); this visual correction does not require a forced update.

Desktop and tablet show two server-card columns with the first four cards filling two rows of the available content height. Phones use one column with approximately two cards in the first viewport; short screens retain readable card sizes and scroll. All five server entries remain available.

This bundled UI patch follows main's 3.5.2 candidate. Staging, real-device acceptance and production publication remain separate release steps; this document does not assert they have completed.
