# Android 2.3.6

- versionName: 2.3.6
- versionCode: 2003006
- Native Bridge: v2 (unchanged)
- Minimum supported version: unchanged at 2003000 (2.3.0).
- Version classification: patch — small authentication recovery and profile error handling fixes; no HTTP or Native Bridge wire changes, feature removal, or new capability.

Profile requests that fail while the account remains authenticated now offer a profile retry instead of reporting an authentication failure. Asynchronous profile results remain owned by the current account. Browser QQ login returns preserve the SDK's state, nonce and PKCE checks: valid anonymous probes settle as signed out, while returns without the original transaction offer explicit recovery and cannot be hidden by an unrelated SSO session. Android browser users see the system-default-browser guidance before login; the APK continues to use its Native authentication owner.

This candidate builds on Android 2.3.5. The frontend is bundled inside APK assets, so the profile runtime change requires a new committed source version. This document records the candidate scope; staging, APK real-device acceptance and production publication remain separate release steps.
