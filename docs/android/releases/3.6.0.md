# Android 3.6.0

- versionName: 3.6.0
- versionCode: 3006000
- Native Bridge: v3, unchanged
- Version classification: minor. Adds per-config turret/gun armor data consumption and a collapsible armor setup card in the shared web UI; no Native Bridge or HTTP wire change.
- Minimum supported version: unchanged; no forced update.

The armor viewer now reads `configs[].turret_plates`, `configs[].gun_plates` and
`configs[].gun_thickness` from `tank/{id}.json` for the selected stock/top configuration.
Missing plate entries fail closed to 0 mm instead of falling back to the top-config
`armor_model` summary.

On desktop the tank info and setup fields share one top-left card. The setup section starts
collapsed behind the 参数 toggle and expands inside the card; the turret/gun angle card remains
in its previous bottom-left position. The mobile portrait layout is unchanged.

Automated validation covers 44 armor/fixture unit tests, CSS lint and the 22-scenario armor browser
geometry/load-order gate (including collision enabled while visual GLB completes before armor). Visual acceptance of the 3D armor scene remains with the user; this document does
not assert staging or publication.
