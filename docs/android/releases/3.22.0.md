# Android 3.22.0

- versionName：3.22.0
- versionCode：3022000（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：minor（新增 Battle Data 出生侧胜率与地图方向覆盖）
- 最低支持版本：保持现有发布配置，不因本版本抬升。

## 说明

- 管理员 Battle Data 页面按地图显示出生侧胜率、样本数与平局率，默认合并随机战与评级战，可切换单一模式；胜率口径为胜场 / 总场次，平局计入总场次。
- 地图统一显示三语本地化名称，最近战斗的地图筛选改为单选；铜矿采集场显示西侧 / 东侧，其余地图显示上方 / 下方。
- 匿名 Battle Data Collector 的物理出生方向覆盖全部 29 张可寻址地图。
- 修复滩涂阵地出生方向颠倒：旧版本客户端采集到的滩涂阵地出生方向与实际相反。
- 不改变匿名采集字段、个人身份或原始回放的隐私边界。
