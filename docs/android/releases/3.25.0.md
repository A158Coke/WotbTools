# Android 3.25.0

- versionName：3.25.0
- versionCode：3025000（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：minor（新增「地图」一级入口：无回放查看 2D/3D 地图并标注，随 web bundle 进 APK）
- 最低支持版本：保持现有发布配置，不因本版本抬升。

## 说明

- **地图预览**：主导航新增「地图」栏（科技树之后，需登录）。从资产包清单选图，
  无回放文件即可查看 3D 场景（俯视/自由飞行相机 + 地形锚定标注）与 2D 战术图
  （拖拽/缩放 + 画笔/橡皮标注），标注支持会话内导入/导出（JSON）。
- **底图双源**：打包注册表收录的 29 张图用离线底图；其余 14 张（矿井阵地、
  变体空间、老版复刻等）回退资产包 `map/<key>/ground.webp`（±300m 契约框），
  全部 43 张图都有封面并可进 2D。
- **不变的部分**：回放工作台五能力、录像者视角与触屏手势、装甲查看器的行为
  与之前相同（3D 场景内核新增的地图预览会话模式不影响回放会话）。
