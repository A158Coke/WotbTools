# Android 3.25.0

- versionName：3.25.0
- versionCode：3025000（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：minor（回放工作台改为选择后自动加载，随 web bundle 进 APK）
- 最低支持版本：保持现有发布配置，不因本版本抬升。

## 说明

- **自动加载**：选择回放后不再需要点「解析预览」，内容直接出现。外部分享回放的自动解析与 ACK 语义不变。
- **管理回放**：添加文件、添加文件夹、单个移除和清空全部集中到页头入口，手机上是底部 sheet。
- **不打断当前场次**：加文件或移除其他回放不会切走正在看的那一场，已开始的 3D 也不会重置。
- **部分失败可继续**：批次里个别回放打不开时只做提醒，其余回放照常使用。
- **改名**：「数据」能力改名「赛后数据」。
