# Android 5.1.0

- versionName：5.1.0
- versionCode：5001000（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：minor（手机横屏紧凑布局、四季氛围背景与玻璃表面、装备矩阵手机分组等体验改进）
- 最低支持版本：保持 5000000（5.0.0），不因本版本抬升。

## 用户可见行为

- 四季主题新增全站环境背景与半透明玻璃面板，页头使用分区主视觉；盛夏主题改为金黄暖色。
- 手机横屏短视口启用场景紧凑档：回放名单与传输条收成单行，装甲查看器、地图 3D 与 HUD 不再互相遮挡，主要触控命中区保持 40px。
- 手机装备矩阵按炮塔 / 火炮 / 发动机 / 履带分组，去掉空格子与孤立标签，窄屏下候选按钮不再重叠。
- 首屏 loader 统一为单层圆环，修复 `corner-shape` 下变形与主题色不一致。

Web 前端随 APK 打包；Native Bridge 与 HTTP 契约不变。3D GPU 画面与 Android 真机体验仍需人工验收。
