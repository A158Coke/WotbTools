# Android 3.24.0

- versionName：3.24.0
- versionCode：3024000（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：minor（3D 回放自由视角改用与键鼠对应的触屏手势，随 web bundle 进 APK）
- 最低支持版本：保持现有发布配置，不因本版本抬升。

## 说明

- **单指拖动**：对应 WASD，贴地平移，地面跟手，高度和朝向不变，松手即停。
- **两指一起拖**：对应按住左键拖动，转视角，上下左右都能转。
- **两指距离变化**：对应滚轮，沿视线推拉相机。
- **不变的部分**：单击选车、绘制工具、沙盘、跟随和录像者的手势与之前相同。
