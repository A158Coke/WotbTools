# Android 3.17.1

- versionName：3.17.1
- versionCode：3017001（由 `wotbVersion` 推导）
- 变更等级：patch。修复 3.17.0 的 HE 溅射兜底语义：采样器“跑了但零有效样本”被误当成“采样器不可用”，回退单射线公式，导致主装全在爆炸半径外的命中显示非零溅射（60TP 炮口样本：285.5，正确为 0）。影响限于 HE 命中履带/炮管/间隙甲等边缘场景，按 patch 处理，不强制旧客户端更新。
- 3.17.0 已取得 immutable tag（`android-v3.17.0`）并完成 stage，不能复用；本候选在其上递增。
- Native Bridge 保持 v3；最低支持门槛保持 `3015003`，不抬。
- Minimum supported version: unchanged at 3015003 (3.15.3).
- 上游 WASM pin：沿用 v0.4.10（ref `a377629ef944274d6b2cdc7363201d9edb6370de`）。

## 修复内容

- 采样器三态：`samples>0` 正常；`samples===0` 是权威零伤害（爆炸半径内没有射线遇到主装，func7695 跳过这类样本）；碰撞包/网格/入参不可用时返回显式 `ERROR`，卡片显示“判定失败 + 溅射采样不可用 · reason”，不再用单射线公式冒充采样结果。
- 单射线公式只保留给从未提供采样器的上游纯函数 / `/api/penetrate` 契约，结果标记 `source:'single-ray', degraded:true`。
- 同类兜底审计：未知弹种不再落到 HE；口径缺失不再静默 120mm；动能弹缺 normalization、非正伤害、非法板厚/法线/命中点均 fail-closed；`fetchShells` 保留判定字段；碰撞包拒绝坏板厚/缺顶点。
- 60TP 炮口命中（爆点 z≈-8.27m，主装最前缘 ≤3.62m，R=3.66m）从 `SPLASH 285.5` 变为 `挡下 / 0`。
