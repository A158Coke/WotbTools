# Android 3.30.0

- versionName：3.30.0
- versionCode：3030000（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：minor（装甲查看器装备 122 接入 + 开镜装甲高亮运行时优化；WASM pin 升到 v0.4.23）
- 最低支持版本：保持现有发布配置，不因本版本抬升。

## 说明

- **装甲查看器接入「改进型垂直稳定器」(设备 122)**：装甲页装备行新增独立勾选，仅当目标车
  `optDevicePreset` 提供该槽位时可用；勾选后拖炮按 `devices.json` 的
  `upperPitchLimitIncrease` / `lowerPitchLimitIncrease`（+4° / +3°）扩展扇区上下限，与
  射界图共用 `pitchAtBearing` 同一实现。射击复现载入时按 `target_equipment.improved_pitch_limits`
  自动勾选；`eqpitch` 随 URL 持久化。可用性预取失败只临时停用并重试，不把瞬时网络失败
  当成「该车不支持」而清掉共享链接覆盖。
- **回放 / 射击侧 122 俯仰解码**：随 APK 打包的 Web bundle 使用 Agent **v0.4.23** WASM pin；
  核心按每个实体自己的 Type5 `0B` 配件串判定 122，在 `prop2` 解码前把基础
  `GunPitchRange` 扩为有效极限，回放炮管角与射击复现的射手/目标炮管时间线同口径。
  边界：若只更新 Web bundle 而 pin 未升到 v0.4.23，装甲查看器的手动 122 勾选仍生效
  （纯前端钳制），但回放/射击的 prop2 俯仰解码不会包含 122 加成；本版本两者同批发布。
- **开镜装甲高亮运行时**：射线拾取先按包围球下界排序并裁剪，进入录像者模式预取装甲模板；
  SNIPER→ARCADE 转换、关闭高亮与退出录像者模式均释放 RT，避免切档后继续占用渲染目标。
  `?perf` 的帧报告将 `renderMs` 与 `armorMs` 分开。
- **不变的部分**：Native Bridge 保持 v3；最低支持门槛不抬升；地图预览、回放工作台其余能力
  与装甲判定规则不变。
