# Android 4.0.0

- versionName: 4.0.0
- versionCode: 4000000
- Native Bridge: v3, unchanged
- Version classification: major — breaking broadcast catalogue HTTP shapes replace a single season name with required Chinese/English and optional Russian names, and replace free-text points-group labels with numeric group identifiers.
- Minimum supported version: set ANDROID_MIN_SUPPORTED_VERSION_CODE to 4000000 before merging/staging this major candidate. Existing production publication is not changed by this source PR.

The season list, breadcrumbs, dialogs and deletion prompts display the configured name for the selected language; Russian falls back to English when absent. Replay titles and team names remain the original source text. Points groups use a positive integer and fixed Chinese/English/Russian labels; they do not inherit the knockout groups' 1–4 cap. Non-numeric legacy group labels are preserved for manual correction rather than guessed.

Existing source names are retained in both required fields during migration, ready for administrator translation. Only source-backed individual matches with confirmed dates, teams and stages are eligible for the initial catalogue data; unavailable, uncertain or incomplete candidates are deferred.

Older APKs reject these new HTTP response shapes and must update. Publish the matching backend and bundled frontend together; set the major floor before stage, then complete APK device acceptance and publish. This file does not establish staging or production publication.
