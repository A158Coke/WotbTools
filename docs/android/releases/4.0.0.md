# Android 4.0.0

- versionName：4.0.0
- versionCode：4000000
- 变更等级：major。联赛回放停止旧 APK 接口兼容，现代三语和时间数据统一使用无版本路径，属于破坏性 HTTP 改动。
- Native Bridge：仍为 v3，RPC 和本地通信契约不变。
- 最低支持版本：本候选发布时为 4000000；合并触发自动 stage 前，需按发布规程完成门槛校验。开 PR 不提前改生产变量或影响尚在 stage 的 3.12.0。

公开接口统一为 `/api/tournament-broadcasts/**`，管理接口统一为 `/api/admin/tournament-broadcasts/**`。移除旧单名/文字小组请求、版本路径、格式转换与读取回退；保留既有现代三语结构、时间 envelope/payload、空组号、区服时区、封面、权限及版本锁。

三语名称与74条回放事实、数据库历史归档和 Flyway V1–V44 保留。仅有旧客户端继续使用的兼容测试删除，业务及数据保护回归继续覆盖。

合并前需确认 #672 的生产后端已部署并可读时间接口，并安排本次接口切换窗口。旧网页不能继续请求已移除的版本路径，新网页不能读取旧后端的单名响应；清理版前后端必须作为一对验收。任何一端失败时恢复成对版本，旧 APK 要求更新。stage 成功与代码合并均不等于生产 APK 已发布。
