# Android 4.0.0

- versionName：4.0.0
- versionCode：4000000
- Native Bridge：v3（additive，保留旧方法）
- 类型：major（客户端更新体验与强制升级）
- 最低支持版本：发布时提高到 4000000（4.0.0），按用户明确要求强制旧客户端更新。

## 用户行为

普通更新显示非阻塞提示；「更多 → 版本 / 关于 WotBTools」提供明确的手动检查、下载进度和安装入口。
相同可选版本选择「稍后」后不重复主动提示，手动检查仍可见；不受支持的版本继续使用 Native 全屏门禁。

用户主动发起的 APK 下载由系统管理并在恢复 App 时对账；SHA-256 验证通过后才能安装，未知来源权限拒绝后保留更新包。
界面显示 versionName，区分等待网络、下载、校验、准备安装和失败，不伪造未知百分比。4.0.0 客户端支持验证后的直接增量更新和失败时回退完整包；由于旧客户端没有增量解码器，首次升级至 4.0.0 仍使用完整包。

版本、最低支持策略、immutable artifact 与 production version.json 最后写入的发布语义保持原契约。
