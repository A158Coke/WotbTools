# Android 2.3.7

- versionName: 2.3.7
- versionCode: 2003007
- Native Bridge: v2 (unchanged)
- Minimum supported version: unchanged at 2003000 (2.3.0).
- Version classification: patch — runtime data-plane and display fixes inside the bundled frontend; no HTTP or Native Bridge wire changes, no feature removal, no new capability.

Shooting inspection no longer bundles its shell-kind table and compact gun-pitch snapshot; both now load from the published asset pack (`/data/shellKinds.json`, `/tank/{id}.json`), so game-balance data refreshes ship through asset uploads instead of app releases. The optional pitch-anchor fetch is bounded (1.5 s) so a stalled asset request cannot hold the shot list, and a late-arriving shell table re-renders through the reactive view. Tank encyclopedia cover art keeps the client-extracted pixels and is re-framed at display time from the per-tank content-box data (`tank_images/crops.json`), restoring the previous tight-crop presentation.

This candidate builds on Android 2.3.6. The frontend is bundled inside APK assets, so the shots/tankopedia runtime changes require a new committed source version. This document records the candidate scope; staging, APK real-device acceptance and production publication remain separate release steps.
