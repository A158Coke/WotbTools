# Android 3.5.2

- versionName: 3.5.2
- versionCode: 3005002
- Native Bridge: v3, unchanged
- Version classification: patch. Small file chooser bug fix; no new capability or wire change.
- Minimum supported version: unchanged; no forced update.

System file picker selections are copied on a background executor through ContentResolver into
private chooser cache before Gecko receives local file URIs. Original basenames and suffixes are
preserved; multi-file selections fail together. Successful files remain available for delayed DOM
File reads until the one-hour cache cleanup. Replay parsing, folder import, and external pending
replay protocol remain unchanged.

Device acceptance is still required: DocumentsUI/Downloads/Google Files (and installed cloud
providers), single/multiple replay, reselection, cancellation, large replay, image chooser, folder
chooser and external-open equivalence. This document does not assert staging or publication.

Both ordinary chooser cache and external pending replay metadata now expire after one hour.
Cleanup remains lifecycle-triggered rather than a background timer; expired external pending
replays are no longer restored after process death.

Chooser copies enforce actual-byte infrastructure ceilings (25 MiB per file, 256 MiB per batch,
128 files), rejecting and cleaning the whole batch on overflow, including missing or false SIZE.
Provider modification timestamps are preserved; missing timestamps use a stable content-derived
fallback so unchanged files deduplicate on reselection. Cache TTL uses the private directory age,
independent of the source file timestamp.
