# Android 2.3.8

- versionName: 2.3.8
- versionCode: 2003008
- Native Bridge: v2 (unchanged)
- Minimum supported version: unchanged at 2003000 (2.3.0).
- Version classification: patch — tank-picker cover display fix inside the bundled frontend; no HTTP or Native Bridge wire changes, no feature removal, no new capability.

The armor viewer's tank selection menu now frames cover art the same way the tank encyclopedia does: the card image box is a fixed 8:5 ratio (previously a fixed 8 rem height, so its aspect drifted with card width) and the client-extracted pixels are re-framed at display time from the per-tank content-box data (`tank_images/crops.json`). Tanks fill the card consistently again, matching the tight-crop presentation restored on the encyclopedia in 2.3.7.

This candidate builds on Android 2.3.7. The frontend is bundled inside APK assets, so the picker display change requires a new committed source version. This document records the candidate scope; staging, APK real-device acceptance and production publication remain separate release steps.
