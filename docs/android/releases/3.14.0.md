# Android 3.14.0

- versionName：3.14.0
- versionCode：3014000
- 变更等级：minor。PR #685 重做 bundled frontend 首页 IA（纯展示页、导航交还侧边栏、Android 条件渲染、reduced-motion、Intl 数字格式与 `/api/hof` 合同消费），属于用户可见的界面功能调整，不新增或删除产品能力，不构成 breaking change；不升 major、不抬强制更新门槛。
- Native Bridge：保持 v3，RPC、本地 origin 和通信契约不变；`contracts/android-native-bridge.json` 不改。
- 最低支持版本：保持 3000000，不因这次首页调整强制更新。

3.13.3 已取得 immutable release identity（`android-v3.13.3` tag 指向 `b333c8c8b21a7a500ae33db99fa80fefd6fff1fa`），不能复用来承载新的 bundled frontend；
本候选从 3.13.3 按 minor 递增至 **3.14.0 / 3014000**，只声明新的候选版本，不代表已 stage、已真机验收或已发布。

#685 的前端变更：首页改为纯展示页，功能导航交还侧边栏；Web 保留 Android 下载 / Sponsor / Feedback 转化入口，Android App 内整张 Android 推广卡不渲染；reduced motion 默认关闭所有动画与 hover 位移 / 缩放；统计数字改用 `Intl.NumberFormat(locale)`；`/api/hof` 纳入 OpenAPI 并在 transport 边界校验 generated `HallOfFamePage`。

本候选继承 [3.13.3](3.13.3.md)；后续 stage、真机验收与 publish 仍按发布规程分别执行。
