# Android 3.32.0

- versionName：3.32.0
- versionCode：3032000（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：minor（名人堂与用户管理分页支持直接跳页）
- 最低支持版本：3017007（沿用当前生产门槛，不变）。

## 说明

- **名人堂分页直接跳页**：单场 / 百场 / 三环公开榜在上一页 / 下一页之外提供页码输入；
  输入 1..总页数后回车或点「前往」直达目标页，只请求目标页一次，不逐页加载中间页。
  空值、非整数、越界与当前页都不发请求；URL 的 `page` 继续同步，刷新 / 分享可恢复。
- **用户管理分页**：同一跳页交互；输入为界面页码（1-based），请求时转换成后端 0-based
  `page`；非 online 时控件禁用，跳页沿用既有选择集清空语义。
- **不变的部分**：Native Bridge 保持 v3；最低支持门槛不抬升；榜单排序、筛选与既有
  上一页 / 下一页语义不变。
