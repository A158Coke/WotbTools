# Android 3.8.1

- versionName: 3.8.1
- versionCode: 3008001
- Native Bridge: v3, unchanged
- Version classification: patch — replace existing broadcast server emblems with the approved local globe illustrations.
- Minimum supported version: unchanged at 3000000 (3.0.0 floor); this visual correction does not require a forced update.

The five region emblems show China, Asia-Pacific, the Americas, Europe and the Russia-focused Lesta view. Their rounded square backgrounds and inset globes scale together at the existing upper-left anchor, retaining the card grid, heights and bottom label positions. English names are CN Server, APAC Server, NA Server and EU Server; the Asia card code is APAC while its stored server key and deep links remain ASIA. Routing, availability and administration behavior remain the same. SVG assets are bundled for both Web and the local Android frontend.

This candidate builds on main's 3.8.0 recommendations feature and uses 3.8.1 for the bundled visual correction. The earlier unmerged 3.7.1 candidate is superseded. Staging, real-device acceptance and production publication remain separate release steps.
