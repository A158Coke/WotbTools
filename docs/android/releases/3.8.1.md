# Android 3.8.1

- versionName: 3.8.1
- versionCode: 3008001
- Native Bridge: v3, unchanged
- Version classification: patch — fix the armor viewer's kinetic-shell penetration semantics for external modules (first-actual-armor normalization / 2×-caliber enhanced normalization) and bring the heatmap and ricochet continuation to parity; unify the armor viewer's tank selector with the Tankopedia list on one shared menu (search aliases / filters / sort / cards / incremental list).
- Minimum supported version: unchanged at the existing 3.0.0 major floor; no forced update for this patch.

The armor viewer now treats external modules (tracks, gun barrel) as flat consumables for the first-actual-armor-layer rule: a kinetic shell that penetrates a module still cannot ricochet, but the first real armor layer behind it keeps its normalization and 2×-caliber enhanced normalization. The click judgment, heatmap and ricochet continuation share the rule; the 3×-caliber `overmatch` flag now reports only the actual caliber rule, and the heatmap keeps the nearest spaced plate's normalization delta when a module is in front.

The armor viewer's target/shooter picker now uses the same `TankCatalogMenu` as the Tankopedia: fuzzy search with search aliases, tier/nation/type filters, name/tier/hp/pen sort, compact chips plus filter sheet, shared cards and incremental loading. Only the dialog shell and the viewer selection callbacks remain page-specific.

This bundled UI patch follows main's 3.8.0 candidate. Staging, real-device acceptance and production publication remain separate release steps; this document does not assert they have completed.
