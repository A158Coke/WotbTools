## 修复内容

- 固定战斗室车辆（GLB 无 `turret_NN` 的 44 台 AT-SPG）：装甲查看器拖曳炮管失效。姿态表收集把“存在炮塔节点”当总开关，`origMatrices` 永不建立，视觉炮管与炮管装甲板都不更新（UI 角度数字仍会变）。改为只要存在炮管组就建立姿态表，炮管组直接吃 `mG = mT·Rx(gr)`（与 3D 回放同一语义）。
- `browser-armor-aiming` 新增无炮塔夹具回归：真实拖动炮管后直接断言视觉炮管与炮管装甲板的矩阵发生变化，并验证 yaw 受 `yaw_limits` 限位；夹具资产包自检同步覆盖固定战斗室的 GLB 结构、装配数学与变体路由。
