# Android 3.3.0

- versionName: 3.3.0
- versionCode: 3003000
- Native Bridge: v3, unchanged
- Version classification: minor — the bundled frontend adds the league livestream replay directory and its administrator forms.
- Minimum supported version: unchanged at the existing 3.0.0 major floor; this feature does not require a forced update.

The More menu opens one shared league broadcast page. Visitors can browse all five servers and open video links without signing in. Real site administrators manage independent seasons, categories, roots and replay entries on the same page. Optional cover images are stored in Tencent COS through the Business API.

Deploy the backend with its forward-only migration before validating the client. COS credentials are optional for browsing and records without covers; cover upload requires the runtime configuration described in `docs/operations/league-broadcast-covers.md`. Native RPC, runtime origin and authentication are unchanged. New public cover URLs resolve through the existing Android business API URL boundary.

This changes the bundled frontend, so it uses a new minor candidate after main's 3.2.0 replay-runtime update. Staging, real-device acceptance and production publication remain separate steps under the existing release workflow; this document does not assert that 3.3.0 has been staged or published.
