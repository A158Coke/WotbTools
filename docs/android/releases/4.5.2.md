# Android 4.5.2

- versionName：4.5.2
- versionCode：4005002（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：patch（坦克百科 XI 默认顶级配置与卡片顶级血量；射击复现保持有证据的升级态）
- 最低支持版本：保持 4.1.0 / 4001000，不因本版本抬升。

## 说明

- XI 车辆详情页、装甲查看器与射手侧在普通装甲检视下缺省采用顶级配置；显式 `upgrade=stock` 仍可回退基础值。
- 射击复现（`shot=`）不把缺失的升级信息补成满级：缺省使用基础数据，只有显式 `upgrade=top` / `supgrade=top` 才作为 what-if 覆盖。
- 坦克卡片血量优先使用上游资产 `tank_cache.hp_top`，普通车辆继续使用 `hp`。
- 旧资产包缺少 `/research/modules/{nation}.json` 或该车 `upgradeProgression` 时保持原始数据，不把旧包打成不可用。
- Web bundle 随 APK 打包，因此递增 Android 源码版本；不抬升最低支持版本。
