# Android 3.5.1

- versionName: 3.5.1
- versionCode: 3005001
- Native Bridge: v3 (unchanged)
- Minimum supported version: unchanged at 3000000 (3.0.0).
- Version classification: patch — fixes missing lower-tier vehicle names in an existing replay data feature; no wire changes or feature removal.

The bundled reference library now loads all tiers 1–10. Lower-tier replays display vehicle names and basic metadata instead of numeric placeholders, and exports use the same library. Existing rating formulas and tier-specific feature gates are unchanged. Models and textures are not preloaded by this change.

This is a source release candidate; staging, device acceptance and production publication remain separate steps.
