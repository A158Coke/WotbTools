# Android 3.10.1

- versionName: 3.10.1
- versionCode: 3010001
- Native Bridge: v3, unchanged
- Version classification: patch — fixes missing lower-tier vehicle names and bundles the all-tier Tankopedia reference data on top of 3.10.0.
- Minimum supported version: unchanged at 3000000 (3.0.0 floor); this fix does not require a forced update.

This candidate builds on 3.10.0 and preserves its unified TankCatalogMenu, national-server search aliases, and armor-viewer fixes. It extends the committed Tankopedia factual library from tiers 7–10 to tiers 1–10 so lower-tier vehicles resolve names and base facts instead of falling back to `#id` placeholders. Equipment, consumable and provision reviewed modeling remains limited to tiers 7–10.

AI free-text vehicle-name correction keeps the full ID/roster lookup while excluding reviewed ambiguous ordinary words and grid-like names from unrestricted prose matching, including Agent, Wind, Fury, Explorer, Ranger, IS and Outcast. Existing R1/R2/R3 correction semantics remain unchanged for unambiguous vehicle names.

The immutable `android-v3.10.0` tag already identifies the previous candidate, so the changed bundled data uses the new 3.10.1 identity. Staging, real-device acceptance and production publication remain separate release steps.
