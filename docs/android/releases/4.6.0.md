# Android 4.6.0

- versionName：4.6.0
- versionCode：4006000（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：minor（增加条件技能模拟开关、技能效果对照和装甲查看器预设视角）
- 最低支持版本：保持 4.1.0 / 4001000，不因本版本抬升。

## 用户可见行为

- 已训练的条件技能默认不计入静态参数，开启模拟触发后才应用有计算模型的加成；训练等级与触发开关分别保存。
- XI 专属技能用互斥卡片选择，并显示同版机制的初始值、当前值与升级变化；缺少已核对基础值时仅显示已知变化。
- 装甲查看器打开参数即可切换 XI 初始/满级状态，切换后保持参数面板展开。
- 静态查看器提供正面、压坡卖头视角；判定卡的 nominal 中文为「板厚」。

Web 前端随 APK 打包；XI 补给/消耗品目录属于独立资产通道，须发布同版客户端导出的资源后生效，APK 不内嵌替代规则。真实 GPU 画面与 Android 真机体验仍需人工验收。
