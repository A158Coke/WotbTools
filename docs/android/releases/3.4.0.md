# Android 3.4.0

- versionName: 3.4.0
- versionCode: 3004000
- Native Bridge: v3, unchanged
- Version classification: minor — the bundled frontend adds bilibili creator recommendations, authenticated favorites, and catalog administration.
- Minimum supported version: unchanged at the existing 3.0.0 major floor; this minor feature does not introduce a forced-update requirement. Publication still compares the candidate major with the actually published version under the existing release guards.

Visitors can browse recommendation categories, creator profiles, optional assessments, recommendation scores and bilibili homepage links. Signed-in users can favorite or unfavorite creators; only first favorites below the score cap contribute reward progress. Tournament administrators maintain the catalog, categories, assessment levels, favorite threshold and optional COS avatars.

This candidate follows the 3.3.0 league-broadcast work, now merged into main. Deploy the backend migrations and API before accepting the client. The shared COS runtime credentials and separate creator-avatar namespace are described in the feature documentation. Native RPC, authentication and runtime origin are unchanged.

This document records the source candidate only. It does not assert a staged APK, device acceptance or production publication. Those remain separate release-workflow steps, including comparison with the actual published major version when applying the minimum-supported-version policy.
