# Android 3.4.0

- versionName: 3.4.0
- versionCode: 3004000
- Native Bridge: v3, unchanged
- Version classification: minor — the bundled frontend adds a dedicated CSV tournament import with preview and confirmed replacement, plus season data-source attribution.
- Minimum supported version: unchanged at 3000000 (3.0.0 floor); this feature does not require a forced update.

Tournament administrators can upload the full standings CSV updated through the current day, inspect the resulting standings and changes, and confirm an atomic replacement. Earlier days are included in each new file and are not added again. JSON historical import keeps its separate, one-time workflow.

Once a season successfully uses CSV import, its public standings retain an `_EK_` source button linking to the user-specified Bilibili page. Preview, failed requests, other seasons and ordinary non-CSV tournaments do not gain that attribution.

Deploy the backend and the existing gateway's CSV capability-header exposure before validating the bundled client. Native RPC, runtime origin, permissions and authentication are unchanged. The current main branch already reserves 3.3.0 for league broadcast replay browsing, so this separate bundled frontend feature uses 3.4.0.

Staging, real-device acceptance and production publication remain separate steps under the existing release workflow. This document does not assert that 3.4.0 has been published.
