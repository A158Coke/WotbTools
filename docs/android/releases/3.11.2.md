# Android 3.11.2

- versionName: 3.11.2
- versionCode: 3011002
- Native Bridge: v3, unchanged
- Version classification: patch — bundled frontend-only permission cutover for recommendation content administration; no wire or bridge change, no forced update.
- Minimum supported version: unchanged at 3000000.

This candidate ships the frontend half of the content-permission cutover. `contentAdminAllowed` becomes the single frontend boundary for the UP/video management entry, the configuration page gate and all creator/recommendation admin request ownership (including the legacy UP-only API). `tournament-admin` no longer exposes or authorizes content management, while the tournament pages keep using `isTournamentAdmin`. The content management page now shows content-specific sign-in and permission-denied copy instead of reusing the league messages. The development-only `?admin=1` shortcut still covers only `wotbtools-admin` / `HoF-admin`; it never grants `content-admin`.

Backend rollout can precede APK publication without invalidating old clients: an old APK keeps gating the entry with `tournament-admin`, so a user who holds only `content-admin` must update the app before managing content. Site administrators are unaffected because Keycloak expands the `wotbtools-admin` composite into both domain roles.

This source candidate does not establish staging, device acceptance or production publication.
