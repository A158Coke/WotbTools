# Android 3.28.0

- versionName：3.28.0
- versionCode：3028000（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：minor（新增站内反馈）
- 最低支持版本：保持现有发布配置，不因本版本抬升。

## 说明

- **站内反馈**：「更多」里的反馈入口不再跳转 GitHub，登录后在应用内提交。提交时记录当前页面，不保存账号信息。
- **站点反馈管理**：站点管理员在独立的「站点反馈」页查看、筛选和删除反馈。
- **HTTP API**：新增 `POST /api/site-feedback` 与 `/api/admin/site-feedback`，现有接口不变，旧版本继续可用，其反馈入口仍跳转 GitHub。
