# HE/HESH 溅射采样

HE/HESH 不再使用 BlitzKit 的单射线溅射公式，改为 Armor Inspector legacy 路径（wasm `func7695`）：

- 采样原点为点击面沿射向外移 0.1 m（与游戏 `func5144` 的 `point = direction × (t − 0.1) + origin` 一致）；
- 800 条固定世界空间方向（20 latitude × 40 longitude，π/20 步长）；
- 沿每条射线累加**名义**装甲层，直到并包含首个 Primary；履带/模块/间隙甲也按层累加，不按 variant 去重；
- `upper = 0.5·D·1.25·(1−d/R) − Σarmor`，`lower = 0.5·D·0.75·(1−d/R) − Σarmor`；
- `he_max = max(upper)`、`he_min = max(lower)`（两个 roll 界各自取最大，可来自不同射线）、`he_avg = (he_min+he_max)/2`，结果下限为 0。

HE/HESH 命中履带/外部模块/炮管/间隙甲首面也进入判定并展示 SPLASH/PENETRATION 卡；没有有效 Primary 射线的采样被跳过，最佳样本不会是履带。结果卡在判定结果右侧显示伤害：纯溅射为 `平均` + 范围小字，1–99% 为满穿伤害 + 小字溅射平均/范围，100% 为满穿伤害，未击穿显式显示 `0`；卡片顶行为交战距离 · 有效穿深 · 溅射半径（仅 HE），直接命中行紧贴最佳样本上方。

HE 热力图按 Armor Inspector shader 67 的局部口径着色：`D·(1−d/R) − 1.3·(thickness+spacedThick)`，按 `D` 归一化；颜色只投影到相机可见的首层主装甲（主装甲深度遮罩对所有弹种开启），后层主装甲不会穿透叠色。已知近似：热力图是逐板局部伤害，未实现“从爆点到该片的首次主装甲遮挡”测试，远侧板在相机转到该侧时仍会按自身距离/厚度染色；面板采样值不受影响。
