# Android 3.16.0

- versionName：3.16.0
- versionCode：3016000
- 变更等级：minor。新增联赛回放同页展开和整个子赛事分类删除，属于中小功能；既有 HTTP 端点继续支持，Native Bridge 保持 v3。
- 最低支持版本：保持现行 `ANDROID_MIN_SUPPORTED_VERSION_CODE=3014002`；本次不抬高门槛、不新增强制升级。

本候选从 main 的 3.15.2 递增，继承其推荐卡片视觉修复及此前 Android 下载点击统计修正。进入赛事后直接浏览所有子赛事；积分赛每轮独立展开，分类小标题展示轮次与回放数量。管理菜单区分单轮删除和整个分类删除，确认前显示影响数量，并使用季赛版本防止过期确认。同步优化窄屏、时区控件、面包屑及回放条目层级。

新客户端依赖新增的赛事内容读取和分类删除端点，后端必须先部署，再切换网页或发布 APK。后端保留既有端点，因此旧 APK 继续使用原有浏览和管理流程；不修改历史初始化数据或迁移。

## 验证与发布

- 后端 57 项定向测试覆盖 HTTP、鉴权、快照一致性、分类隔离、版本冲突及封面引用保护。
- 前端定向测试、类型检查、样式检查和 22 个浏览器场景通过；另检查管理态桌面／手机布局。
- OpenAPI、fixture 与生成契约校验通过；repository-level validation 由 PR CI 执行。
- 本文件仅声明候选版本。合并后仍须后端部署、Android stage、真机验收及 publish；本次未发布 APK。
