# HE/HESH 溅射采样

HE/HESH 不再使用 BlitzKit 的单射线溅射公式，改为 Armor Inspector legacy 路径（wasm `func7695`）：

- 采样原点为点击面沿射向外移 0.1 m（与游戏 `func5144` 的 `point = direction × (t − 0.1) + origin` 一致）；
- 800 条固定世界空间方向（20 latitude × 40 longitude，π/20 步长）；
- 沿每条射线累加**名义**装甲层，直到并包含首个 Primary；履带/模块/间隙甲也按层累加，不按 variant 去重；
- `upper = 0.5·D·1.25·(1−d/R) − Σarmor`，`lower = 0.5·D·0.75·(1−d/R) − Σarmor`；
- `he_max = max(upper)`、`he_min = max(lower)`（两个 roll 界各自取最大，可来自不同射线）、`he_avg = (he_min+he_max)/2`，结果下限为 0。

HE/HESH 命中履带/外部模块/炮管/间隙甲首面也进入判定并展示 SPLASH/PENETRATION 卡；没有有效 Primary 射线的采样被跳过，最佳样本不会是履带。结果卡在判定结果右侧显示伤害：纯溅射为 `平均` + 范围小字，1–99% 为满穿伤害 + 小字溅射平均/范围，100% 为满穿伤害，未击穿显式显示 `0`；卡片顶行为交战距离 · 有效穿深 · 溅射半径（仅 HE），直接命中行紧贴最佳样本上方。

HE 热力图按 Armor Inspector shader 67 的局部口径着色：`D·(1−d/R) − 1.3·(thickness+spacedThick)`，按 `D` 归一化；颜色只投影到相机可见的首层主装甲（主装甲深度遮罩对所有弹种开启），后层主装甲不会穿透叠色。已知近似：热力图是逐板局部伤害，未实现“从爆点到该片的首次主装甲遮挡”测试，远侧板在相机转到该侧时仍会按自身距离/厚度染色；面板采样值不受影响。

炮弹轨迹、命中标记和溅射半径球在热力图之后绘制，不会被首层着色遮挡。间隙甲材质保持双面显示，但点击/续飞判定按采样网格/BlitzKit 的 FrontSide 口径剔除背面命中（闭合屏幕的正、背面不再重复计层）；HE 800 射线采样保留 `twoSidedSpaced`（从背面命中的间隙屏仍参与溅射）。主装甲保持单面语义。

间隙甲重复计层修复（2026-10-20）：点击/续飞 raycaster 读取的是双面渲染材质，闭合间隙甲（如 Kranvagn `gun_01_armor_9`）被正、背两面各计 50mm，结果卡同一 `炮盾装甲板 9` 出现两次（52.1mm @25° / 52mm @24°），把 250mm 穿深误判为未击穿。`classifyHit` 现在返回 `backface`，主判定与续飞两处命中收集均剔除背面；显示材质仍为 DoubleSide，HE 采样网格保留 `twoSidedSpaced`。判定口径与 GPU 采样网格/BlitzKit 一致。

射击复现的续飞反射方向已修正：`__segRay.dir` 本身就是 P1→P2 入射方向，不再在续飞前二次取反（此前反射线会被送到射手一侧）。

世界系续飞网格改为按各网格 `matrixWorld` 快照判失效：姿态入口不止「炮塔/炮管旋转」一处（射击回放的时间滑块与初始摆放直接写车体位姿，不经过 `updateTurretGun`），漏标 dirty 会让逐像素续飞继续用旧姿态的网格，而点击判定用实时矩阵——实测 8° 车体偏航：4215 个采样像素中 94 个 CPU/GPU 续飞结论不一致（转回原姿态后网格与新姿态重新一致而恢复）。同日报告的 KRV 混色带经排查是两块重叠主装甲板在 MSAA 下的样本平均，与本网格过期无关，见 docs/research/armor-inspector-mixed-color-investigation.md。现在每帧比对网格矩阵快照，变了才重建，静态视图零额外开销。

AP/APCR 热力图不再给炮管外部模块涂 `EXTERNAL_FRAG` 的厚度/穿深紫（调试 hover 的 `gunBarrel 50mm | cls=1 | gpu=179,51,189` 就是这层色）；炮管的深度/RT1 状态保留用于遮挡其后装甲，HE 溅射覆盖层仍单独采样炮管。 RT1.A 标记外部模块在该像素位于主装甲之前时，主装甲热力图片元直接 discard——不再把其后的主装甲颜色以 0.5 alpha 画到炮管/履带表面（KRV 炮盾投影混色的直接原因）。

跳弹续飞共面排序回退（2026-10-20 P0 清理）：原 PR #713 的 `COINCIDENT_EPSILON = 20 µm`、`compareContinuationHitOrder` 模块优先、GPU cell 游标保留与候选 variant 过滤已移除。其唯一真实样本 KRV 炮管命中点在 `gunClipPlane` 负侧，已由 gun_mask 裁剪在排序前剔除；续飞/点击/JS/GPU 现在只按命中距离排序，不再有 20 µm 特判。

gun_mask 负侧炮管剔除（2026-10-20）：Kranvagn 4481 config 0 的跳弹续飞射线会打到 `gun_01` 后段（炮尾/炮盾内壁），该段在点击画面的 `gunClipPlane` 负侧（复算距离 −0.61/−0.79/−0.88 m），视觉上被裁掉；旧点击续飞循环没有主判定循环的裁切过滤，把它当 50 mm 外部模块消费，概率卡从 100% 降到 67%。现在 `isClippedModuleHit` 单一判据同时用于点击主判定/续飞、JS `raycastPackAll`/`simulateContinuation`、HE 采样；GPU `rcContinue` 通过 `rcClipEnabled`/`rcClipPlane`（世界系 vec4，`renderSpacedArmorPass` 每帧同步）在候选排序前跳过负侧 `gunBarrel`。只过滤炮管模块，Gun Plate 7 炮盾仍按 70 mm 参与；KRV 该样本剩余炮盾 187.5 mm > 136.12 mm → PENETRATION/100%，层链不再出现炮管。裁切面按 BlitzKit `SpacedArmorScene` 的固定模型前向平面构造（`maskOrigin = gun.mask + hullOrigin.y + turretOrigin.y + gunOrigin.y`），不再取炮管世界 AABB 最长轴；可见炮管（裁切面正侧）仍按普通外部模块参与，续飞排序只按距离。

主装甲渲染回退（2026-10-20 P0 清理）：移除 `primaryResultRT` 单样本离屏缓冲与 `NoBlending`，恢复 `excludeMaterial` 深度遮罩 + `clearDepth` 直接渲染；5177 的 clip-only 对照已证明该显示问题不依赖离屏缓冲。移除 `moduleInFront` 的 `discard`、炮管跳过 `EXTERNAL_FRAG` 颜色 clone、独立 `shotOverlayScene`；轨迹/命中标记回到主场景。片元 shader 保留整体 `precision highp float`、`highp sampler2D` 与矩阵精度，删除逐 uniform/局部变量的冗余 `highp`。姿态快照/网格重建、1–5 px 微动门控、续飞反射方向修复保留。

跳弹续飞两次上限（2026-10-20）：首段跳弹后再执行一段续飞（剩余穿深 ×0.75），该段只有首个命中层可再次跳弹；第二次跳弹即终态，炮弹消失，不再做第三段判定，结果卡终态为 RICOCHET/0%。结果卡的击穿概率行置于最终判定结果标题下侧；模块/间隙甲前置仍抑制跳弹；续飞首层为间隙甲时也执行这次跳弹判定。无效 HE（零/缺失爆炸半径）的概率行 fail-closed 为 0%，不沿用穿透原始值。

P1 装甲判定清理（2026-10-20）：装甲 section 直接使用客户端数据（hull/turret/gun + armor_N，spaced 由客户端 spaced 列表决定），不再把非 spaced 的 gun 板 retag 成 turret；点击/续飞可见性向上遍历到模型根之前（模型根 visible 是视图开关，不当作部件隐藏）；`gun_XX`/`gun_XX_mask` 才是外部炮管模块，`hide_elements`/`state_XX` 拆件改为 display-only deco，不再消耗 50mm。0mm Primary 视为合法 Primary，与 10mm 板走同一 `hasPrimaryLayer`/概率链路径；空概率链改为 fail-closed 0%。
