# Android 3.13.2

- versionName：3.13.2
- versionCode：3013002
- 变更等级：patch。PR #688 修的是 bundled frontend 的用户可见缺陷（教程导出/焦点与 Escape、名人堂上传弹层键盘、AI 复盘原始 Markdown 残留、战队汇总三语表头），不新增或删除功能，不构成面向已有用户的破坏性升级；不升 major/minor，不抬强制更新门槛。
- Native Bridge：保持 v3，RPC、本地 origin 和通信契约不变；`contracts/android-native-bridge.json` 不改。
- 最低支持版本：保持 3000000，不因这次修复强制更新。

3.13.1 已取得 immutable release identity（`android-v3.13.1` tag 指向 `1f00bc66e75890cbe8bc116307cebffcb5ee403f`），不能复用来承载新的 bundled frontend；
本候选从 3.13.1 递增 patch 至 **3.13.2 / 3013002**，只声明新的候选版本，不代表已 stage、已真机验收或已发布。

#688 的前端修复：教程数据与导出步骤中说明卡不再盖住展开的导出菜单，且教程期间的导出下载不再被背景点击隔离拦截（只放行 downloadBlob 产生的隐藏下载 anchor）；
列选择浮层改为非模态对话框（打开取焦点、Esc/Done 关闭并把焦点还给触发按钮），引导把 Escape 先交给真实伴随层（含展开的 combobox）；
名人堂上传弹层打开即聚焦可见控件、Esc 可关闭并归还焦点；AI 复盘完成后不再残留原始 Markdown；战队汇总表头补齐三语 `rated_battles`/`league_observed_mean`；
教程示例加载改由独立生命周期持有，退出后不再有迟到的 capability 切换，Retry 保留当前 guide 节点。

本候选继承 [3.13.1](3.13.1.md)；后续 stage、真机验收与 publish 仍按发布规程分别执行。
