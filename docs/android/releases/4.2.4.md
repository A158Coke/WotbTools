# Android 4.2.4

- versionName：4.2.4
- versionCode：4002004（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：minor（资产数据版本通道配套：本版起 APK 内的 `AgentAssetProxy` 支持
  `/agent-assets/v/<dataset-id>/...` 原样透传到远端资产 origin 的版本化 dataset 路径，
  与 Web 端「数据版本」选择器同批；不涉及解析契约、回放权威输入与 WASM pin）
- 最低支持版本：保持 4.1.0 / 4001000，不因本版本抬升。

## 说明

- **数据版本通道透传**：旧 APK 只能读资产 origin 根路径（`current` 指向的默认
  dataset）；本版起 `AgentAssetProxy` 对 `/agent-assets/v/<id>/...` 做路径透传，
  用户（或远端配置）指定 dataset 后，地图/坦克/配置器数据可按游戏版本通道取用，
  不同 dataset 的磁盘缓存 key 天然隔离（key 含完整请求路径）。
- **默认行为不变**：未指定 dataset 时仍走根路径 = origin 默认 dataset
  （当前为 `supertest` / `t11p2-20261106`，743 辆含 5 辆 11.22 预览 XI）。
- Web 同批能力（侧边栏数据版本下拉）随前端镜像发布；`/versions.json` 与
  `/v/<id>/...` 需 asset-origin Caddy redeploy 后生效。
- Agent WASM pin 不变。发布说明在发布时归档。
