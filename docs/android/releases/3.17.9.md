## 说明

- 坦克百科详情态新增整合配置器：模块（炮塔/炮/发动机/履带）、装备 9 槽、补给、消耗品、
  乘员技能、涂装与 URL 状态；参数区由纯函数引擎按客户端数据实时计算，并与装甲查看器
  `?config=` 联动。
- 新增 `common/research/` 客户端研发数据快照（738 辆 / 9 国别模块、24 装备 + 9 预设、
  64 消耗品 / 85 补给、20 项乘员技能、弹种与物品图标；`meta.json` 记录客户端版本与
  逐文件 sha256）。
- 计算口径：BK 公式 + 客户端数值；隐蔽按客户端 `camouflages.xml` / 迷彩网 script 以
  百分点绝对值相加；补齐弹夹/自动装填 DPM、自动装填有效 DPM、履带维修、车体尺寸、
  初始 pitch 与五态隐蔽。
- 无炮塔车按客户端 `hasTurret=false`（车辆 XML `<hull><fakeTurrets>` 结构标记，738/738
  与 BI 11.21 一致）把「炮塔转速」行替换为「火炮转向速度」。
- 离开坦克百科时清理全部配置器 query 键（`engine/track/shell/dev/cons/prov/skills/camo`），
  避免泄漏到其他视图。
