# Android 5.4.0

- versionName：5.4.0
- versionCode：5004000
- minor 中小功能，随 APK 打包的坦克百科、装甲选车和科技树使用客户端分类图标，并新增普通、金币、典藏筛选。
- Native Bridge：v4，最低支持版本 5004000（5.4.0）——`latestVersionCode = minSupportedVersionCode`，全员强制升级（2026-11-14 用户要求）。

手机和矮横屏使用筛选 sheet，车型搜索、当前车辆配置与筛选条件可在布局切换中保持。中国使用用户提供的 CN 标识，other 显示为闪电系。本条记录候选功能，真机与发布证据在实际验收后补充。

强制升级动机：线上全体客户端（≤5.1.0，2026-11-09 发布）的内置 bundle 早于 2026-11-11 的 dataset id `_` 字符集放宽，资产 origin 新增 `11.21.0_1` dataset 后其版本选择器对 catalog 整目录 fail-closed（用户反馈「版本列表加载失败」）；同时前端已只支持 Native Bridge 4，`guard_min_supported` 要求 floor 覆盖全部 bridge-3 客户端。随本候选 publish 将两者一并解决：升级到 5.4.0 即取得带修复的 bundle。

发布路径（2026-11-14 review 核对）：本候选前置为 docs-only 变更，`android-release.yml` 的 push 触发 paths 仅含 `android/gradle.properties`，因此 docs 合并不触发自动 stage；`android-auto-publish.yml` 只续跑 `event == push && head_branch == main` 的 stage，对手动 stage 不自动续跑。确认 5.4.0 未被 tag / origin APK / staging evidence 消耗后（2026-11-14 核对：尚无 `android-v5.4.*` tag），从最新 main 显式 `workflow_dispatch(mode=stage)`，成功后再显式 `workflow_dispatch(mode=publish, version=5.4.0)` 写 production `version.json`。变量设置、stage 完成、文档合并都不等于门槛已生效。
