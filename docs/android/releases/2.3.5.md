# Android 2.3.5

- versionName: 2.3.5
- versionCode: 2003005
- Native Bridge: v2 (unchanged)
- Minimum supported version: unchanged at 2003000 (2.3.0).
- Version classification: patch — small compliance/UI display change; no breaking behavior, Native Bridge wire change, feature removal, or core correctness impact.

Patch release for the Android app footer. The bundled frontend now displays the approved APP ICP filing number `闽ICP备2026036303号-2A` when running inside the Android app, while browser builds keep the website filing number `闽ICP备2026036303号-1`. The filing remains linked to the MIIT filing query site. In Android the link does not request a new WebView target, allowing the existing main-frame HTTPS external-navigation handler to hand it to the system browser. Builds on Android 2.3.4 and retains its 3D replay fixes. This version bump is required because Android ships the frontend inside APK `assets/web`; deploying the website alone cannot update installed apps. The `android/gradle.properties` change puts 2.3.5 on the normal staging path after merge. Production `version.json` changes only through the separate publish flow.
