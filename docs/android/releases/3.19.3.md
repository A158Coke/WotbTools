- Native Bridge：v3（不变）
- 类型：patch（3D 场景相机行为变化，随 web bundle 进 APK）
- 最低支持版本：保持现有发布配置，不因本版本抬升。

## 说明

- **车辆检视装载区图形化**：消耗品 / 补给 / 装备只显示图标（名称进无障碍标签）；装备串按紧凑线序只展示实际装配，不按数组位置推断语义槽位。防破片内衬使用 `anti-high-explosive` 图标；已装备但缺图用实线警示占位，与空槽虚线占位可区分；装备目录加载失败时也保持非空缺图状态（加载中为中性实线），不误报未装备。波兰补给 `0x6D/0x6E` 按 11.18/11.20 回放证据（60TP 仅 `0x6D`，53TP 同时带 `0x6D+0x6E`）补入映射；`0x6E` 的大/小由成对线序闭合。
- **默认视角**：3D 回放进入时默认使用俯视（Top），围绕地图中心；用户切到 Follow/Free 后同一会话内保持其选择。
- **相机旋转中心**：跟随视角以选中坦克为中心（沿用）；俯视从一次性快照改为**持续模式**，
  以地图中心为 OrbitControls target，拖拽/滚轮围绕地图中心旋转/缩放，极角限制在地平线
  以上；Top/Follow 禁用 pan（双指只缩放）；自由视角保持原 FPS 行为不变。相机挡位选择合并为 Free / Follow / Top 三档。
- **地形放大阻挡**：跟随/俯视下放大时，若相机将进入地形，沿 target→camera 射线按新 x/z
  逐轮重采样地形，找到净空点后把相机拉回并把 `minDistance` 锁在该距离（贴限期间保持锁定），
  继续滚轮不会钻进地形或漂到异常位置；射线无安全交点时在相机当前 x/z 垂直抬到净空之上。
  Follow 极角限制在地平线以上，不能向下绕到地下。相机真正升高离开限制后才复位，target
  （旋转/缩放中心）全程不变。
