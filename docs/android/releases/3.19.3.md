# Android 3.19.3

- versionName：3.19.3
- versionCode：3019003（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：patch（3D 场景相机行为变化，随 web bundle 进 APK）
- 最低支持版本：保持现有发布配置，不因本版本抬升。

## 说明

- **相机旋转中心**：跟随视角以选中坦克为中心（沿用）；俯视从一次性快照改为**持续模式**，
  以地图中心为 OrbitControls target，拖拽/滚轮围绕地图中心旋转/缩放，极角限制在地平线
  以上；自由视角保持原 FPS 行为不变。相机挡位选择合并为 Free / Follow / Top 三档。
- **地形放大阻挡**：跟随/俯视下放大时，若相机将进入地形，按地形高度 + 净空把相机沿
  target→camera 拉回并把 `minDistance` 锁在该距离，继续滚轮不会钻进地形或漂到异常位置；
  缩小后相机升高、`minDistance` 复位，target（旋转/缩放中心）全程不变。
