## 修复内容

- 3D 回放血量链：丢视野（AoI 隐藏段）期间的盲炮/视野外掉血在二次点亮时刻兑现（上游 Agent
  v0.4.12→v0.4.13）。Type4 隐藏段零更新（type=7/8/10 全断），method1 只覆盖在场段——此前该类
  掉血在 `vehicles[].hp` 上无体现，坦克重入后 HP 条停在丢视野前旧值、直到下一次受击才被动修正
  （实测 J20 场 CN_LEVITHAN：在场末 1192 → 重入快照 348，缺 844 点）。现按全部血量证据统一
  按时间合并（同钟快照在前）、最后相邻同值去重的口径重建血量链：隐藏段掉血在二次点亮落台阶，
  伤害飘字（血量链差分）随之自动出现一次聚合伤害事件；复活回满血再受击的同值边界由 v0.4.13
  修正（v0.4.12 的先去重后并入会吞掉被快照分隔的同值 method1）。
- 3D 回放死亡归属：隐藏段死亡后残骸重入（重入 Type5 快照为终态 0/哨兵）时，随后/同钟的
  method1 归零事件的凶手/死因不再被显示去重吞掉（上游 v0.4.14）——`death_t` 的
  `killer_eid`/`cause` 对该场景恢复 method1 归属（v0.4.13 会退化 0/255 甚至丢失）。
- 凶手归属边界不变：隐藏段掉血本身仍无 per-hit 事件与凶手归属（上游 fail-closed）。
  契约见 `contracts/agent/replay-facets-v2.md` §4m。
