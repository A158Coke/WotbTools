- versionName：5.2.1
- versionCode：5002001（由 `wotbVersion` 推导）
- Native Bridge：v4（不变）
- 类型：patch（超测服 11.4.0.138 数据面适配：XI 强化树图标/文案补全、卡片满强化穿深）

## 用户可见行为

- 坦克百科列表卡片的穿深改为「无配件 + 强化树点满」（与血量卡片同口径）：资产包新增逐弹
  `penetration_top` / `damage_top`，缺字段的普通车继续显示基础值。
- XI 研发树补全 t11r3（11.4.0.138）4 辆新车的强化图标与三语文案：副炮（辅助武器）、
  非制导火箭、弹药热控、弹药补给模块，以及 22 个此前会显示原始键的属性名。
- 机制参数面板对热控/弹药补给显示客户端同版基值（最高蓄能车速、蓄能时间、触发延迟、
  最小伤害提升、触发条件）；副炮/火箭的伤害与装填来自各自火炮定义，面板只显示升级改变量。

Web 前端随 APK 打包；Native Bridge 与 HTTP 契约不变。3D GPU 画面与 Android 真机体验仍需人工验收。
