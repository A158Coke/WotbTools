# Android 2.5.0

- versionName: 2.5.0
- versionCode: 2005000
- Native Bridge: v2 (unchanged)
- Minimum supported version: unchanged at 2003000 (2.3.0).
- Version classification: minor — adds bounded, best effort product usage telemetry to the bundled frontend. Existing clients remain compatible; no Native Bridge change or mandatory upgrade.

Foreground signed-in activity contributes to active-user counts after server token validation. Feature page opens and per-file replay parse attempts/outcomes are reported without file names, replay contents, raw errors or persistent anonymous identifiers. Telemetry failure never blocks local replay analysis. Events use a bounded memory queue without offline persistence.

This source candidate builds on 2.4.0. APK staging, real-device verification and production publication remain separate release steps. Keep the current minimum for same-major publication; compare the selected candidate against production metadata before publishing.
