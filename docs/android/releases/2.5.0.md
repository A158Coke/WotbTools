# Android 2.5.0

- versionName: 2.5.0
- versionCode: 2005000
- Native Bridge: v2 (unchanged)
- Minimum supported version: unchanged at 2003000 (2.3.0).
- Version classification: minor — a new capability inside the bundled frontend (COS-hosted 2D basemap update channel, "bundled fallback + online verification") plus a change of the bundled basemap bytes; no HTTP or Native Bridge wire changes, no feature removal, no new permission.

The 2D tactical basemaps now ship **byte-identical to the web build** (the ≤1024² Pillow derivation for Android is removed; the whole pipeline, its invariants and its CI steps are deleted). The 29 basemaps themselves are re-sourced: they are derived in the upstream Agent repository from the asset pack's `ground.webp` with a frozen recipe, and the archived AI-enhanced client-originals batch is retired.

A new runtime channel lets an already-published map's basemap update **without an APK release**: the app compares a COS-hosted `map2d/index.json` (per-map sha256 + a content generation timestamp) against the sha256 recorded for the bundled copy, fetches only maps whose content actually changed, verifies every downloaded byte against its sha256 before use, and falls back to the bundled copy on any failure (offline, mismatch, unverifiable). The comparison is monotonic in the basemap content's own generation timestamp, so a stale local cache — or a map set published before this APK was built — can never downgrade what the user sees. Adding a *new* map still requires a release (the registry and the parser WASM are bundled).

APK payload grows by ~13.4 MiB (2D basemaps 8.14 → 21.5 MiB) because the bundled copy is no longer downscaled; this is the deliberate trade-off for pixel-identical 2D maps across web and Android and for a full-quality offline fallback.

This candidate builds on Android 2.4.0. The frontend is bundled inside APK assets, so both the basemap swap and the update channel require a new committed source version. This document records the candidate scope; staging, APK real-device acceptance and production publication remain separate release steps.
