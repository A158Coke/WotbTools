# Android 5.1.2

- versionName：5.1.2
- versionCode：5001002（由 `wotbVersion` 推导）
- Native Bridge：v4（`setLandscapeLock{locked}` 改为 `setOrientationLock{orientation}`，移除旧方法，属 breaking）
- 类型：minor 行为（回放查看器方向 / 自动全屏）
- 最低支持版本：保持 5000000（5.0.0），不因本版本抬升。

## 用户可见行为

- Android 手机上，回放工作台的 2D / 3D / 射击复现在回放成功就绪后自动进入横屏全屏；退出全屏回到竖屏，回放不中断；主动退出后不会自动重入。
- 平板、移动浏览器、桌面与 iPhone Safari 行为不变。
- 原生配置 `full-screen-api.allow-trusted-requests-only=false`（`GeckoRuntimeConfig`）使异步就绪后的自动全屏不被 Gecko 拒绝；全屏仍由 Gecko 持有。

自动全屏的真机效果与 GeckoView 配置的运行时行为仍需人工验收。
