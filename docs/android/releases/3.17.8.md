# Android 3.17.8

- versionName：3.17.8
- versionCode：3017008（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：patch（版本承接，无功能改动）
- 最低支持版本：恢复为 3015003（3.15.3）——撤回 3.17.7 发布的 3017007 门槛。
- 上游 WASM pin：v0.4.14（ref `f739030258bce1e027db8848b2dad75efd148df3`，与 3.17.7 相同）。

## 说明

- **门槛撤回**：3.17.7 以 `minSupportedVersionCode = 3017007` 发布（用户仅要求发布最新版本，未要求抬门槛）。同版本 manifest 不可就地改写（publish 的 `classify_prod` 对同 versionCode 不同门槛判 `prod_equal_conflict` 并 fail-closed），因此以 3.17.8 的新清单撤回：`latestVersionCode = 3017008`、`minSupportedVersionCode = 3015003`。低于 3.15.3 的客户端仍强制更新；3.15.3 及以上恢复为可选更新提示。
- **功能与 3.17.7 相同**：APK 仅 `versionCode` 不同；携带同一 Agent pin（v0.4.14）与前次合并的全部内容。

## 验证

- 本文件仅声明候选版本；合并后由 stage 构建/签名/seed/tag/evidence，真机验收通过后 `publish(version=3.17.8)` 写 `version.json`。
