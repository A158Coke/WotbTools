# Android 3.3.1

- versionName: 3.3.1
- versionCode: 3003001
- Native Bridge: v3, unchanged
- Version classification: patch — enlarge the existing broadcast server cards and move the existing page into primary navigation.
- Minimum supported version: unchanged at the existing 3.0.0 major floor; this UI correction does not require a forced update.

League broadcast replays appear directly after league standings in the shared primary navigation. More no longer duplicates the entry. Phone tabs and the collapsed sidebar use a short localized caption while retaining the full accessible name. Server cards are taller and wider before wrapping on smaller screens.

The `android-v3.3.0` tag already fixes the previous candidate, so the changed bundled frontend uses a new patch version. APK staging, device acceptance and production publication remain separate steps; this document does not assert that 3.3.1 has been staged or published.
