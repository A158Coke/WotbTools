# Android 2.3.3

- versionName: 2.3.3
- versionCode: 2003003
- Native Bridge: v2 (unchanged)
- Minimum supported version: unchanged at 2003000 (2.3.0).

Patch release that makes the shared 3D replay terrain load publish-safe. The terrain metadata and the heightfield are separate downloads, so during an asset publish a client could pair new metadata with an older cached heightfield (or the reverse) and draw the terrain one heightmap texel out of place. The frontend now requests the heightfield keyed by the `terrainBinSha256` declared in the metadata and verifies the bytes before decoding; a mismatch falls back to the 2D ground instead of rendering misaligned terrain. Packs without the hash load exactly as before. Builds on 2.3.2. Stage builds and verifies the immutable APK and evidence; production version.json changes only through a separate publish run.
