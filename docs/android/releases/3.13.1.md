# Android 3.13.1

- versionName：3.13.1
- versionCode：3013001
- 变更等级：patch。本次按用户明确确认的例外处理：待清理的旧内容接口只用于内部测试，尚无用户使用，不构成面向已有用户的破坏性升级；不升 major、不抬强制更新门槛。
- Native Bridge：保持 v3，RPC、本地 origin 和通信契约不变。
- 最低支持版本：保持 3000000，不因这次兼容清理强制更新。

联赛回放统一使用 `/api/tournament-broadcasts/**` 和 `/api/admin/tournament-broadcasts/**`，保留现代三语、时间 envelope/payload、时区、空组号、封面、权限和版本锁，删除旧版本路由及旧 APK 格式适配。时区选择器改为单行图标控件，手机端操作按钮与时区分两行。

Bilibili UP/视频推荐只使用 `/api/recommendations/**` 和 `/api/admin/recommendations/**`；删除旧 UP-only CRUD、DTO/service/mapper 适配和前端回退。等级管理迁到现行 recommendations 下；已保存图片继续使用 `/api/creators/avatars/{id}`，不破坏图片引用。健康能力仅以 `recommendations-v1` 声明推荐功能。

这不恢复旧客户端的接口支持；内部测试客户端应使用新候选。数据库实体、既有迁移、74 条回放事实、历史归档和图片生命周期保留。

#683 已先合入 main，源码为 3.13.0，因此本候选以它为基线递增 patch 至 3.13.1；继承 [3.13.0](3.13.0.md) 的装甲判定/概率与场景改动。先确认前置后端已部署，再安排本次前后端切换并成对验收；任何一端失败时恢复成对版本。stage、真机验收和 publish 仍按发布规程分别执行。
