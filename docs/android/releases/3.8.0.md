# Android 3.8.0

- versionName: 3.8.0
- versionCode: 3008000
- Native Bridge: v3, unchanged
- Version classification: minor — curated Bilibili video recommendations alongside the existing UP directory, with backward-compatible UP APIs.
- Minimum supported version: unchanged at the existing 3.0.0 major floor; no forced update for this minor release.

The Bilibili recommendations entry opens type cards for recommended UPs and excellent videos. Visitors see populated types and categories; administrators retain empty types and maintain both through one configuration page. Video records use case-preserving BV identifiers, generated video links, manual stars and optional proportionally displayed covers; they have no author relationship or skill assessment.

Existing UP deep links remain usable. Type changes use browser history and ask before discarding unsaved inputs or images. Uploads reuse site-owned images compressed to a longest edge of 256px and the existing daily unreferenced-image cleanup.

New clients use the typed API only after the backend advertises recommendations-v1; older backends retain the UP-only fallback. Older APKs continue using unchanged UP APIs. Deploy the type-aware backend before enabling videos; the shared database migration preserves existing UP records and dictionaries.

This source candidate does not establish APK staging, device acceptance or publication. Existing immutable identity and release guards apply.
