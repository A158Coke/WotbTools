# Android 3.1.0

- versionName: 3.1.0
- versionCode: 3001000
- Native Bridge: v3, unchanged
- Version classification: minor — the bundled frontend adds global default tournament rules and their administrator editor.
- Minimum supported version: unchanged at the existing 3.0.0 major floor; this feature does not require a forced update.

Tournament administrators can select “全局默认配置” in the season selector, edit its complete rules, or promote a saved season's rules with an explicit replacement confirmation. Seasons without custom rules inherit the default until statistics begin, when their rules are frozen. Existing results do not change when the default changes.

The backend Flyway migration initializes the approved 2026 Fire Cup rules once. Deploy the backend and gateway capability-header CORS support before validating the bundled client; an older backend without the capability header keeps ordinary season management available. Native RPC, runtime origin, permissions and authentication are unchanged.

The existing `android-v3.0.0` tag already fixes the previous candidate identity, so the changed bundled frontend requires a new version. Staging, real-device acceptance and production publication remain separate steps under the existing release workflow; this document does not assert that 3.1.0 has been published.
