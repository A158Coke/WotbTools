# Android 3.1.0

- versionName: 3.1.0
- versionCode: 3001000
- Native Bridge: v3 (unchanged)
- Minimum supported version: unchanged at 3000000 (3.0.0 floor).
- Version classification: minor — a bundled-frontend runtime change inside playback (2D pose now shares the
  3D scene's channels, follows the client filter semantics: freeze when the vehicle leaves view; markers no
  longer displaced from their true position; the 3D ground uses the contract `ground.webp` for every quality
  tier; OTA basemap swaps now require a matching world-bounds/orientation declaration). No HTTP or Native
  Bridge wire changes, no feature removal, no new permission.

Unpublished candidate at the time of writing (not staged, not published); the record below is the change it
carries, and staging still requires the documented stage → on-device verification → publish flow.

What changes for users:

- **2D 回放位姿与 3D 同源**：车辆位置/朝向取同一份通道（`pose_kf` 关键帧优先），失去视野后图标停在最后
  观测点（不再跟随客户端滤波器的预测延续），重新被点亮时从新位置继续。
- **标记严格落在真实位置**：此前"防重叠推开 + 虚线回指"的 2D 布局删除，密集区域允许图标互相压盖
  （与 3D 一致）；名牌 / 血量块的防重叠不受影响。
- **地面贴图四档统一**：最低画质档不再使用客户端 HUD 小地图（它覆盖约 620 m、多出外围一圈），四档
  都用 ±300 契约底图，与 2D 地图同框。
- **OTA 底图更严**：远端底图换图前必须声明并通过世界框/取向/像素尺寸校验，任一不符即回落包内
  （旧 schemaVersion 1 索引一律不换）。
- **复活模式生命状态（#622 前端半）**：回放消费上游复活轨道（`death_times`/`resurrection_times`）——
  复活模式的车辆复活后不再停在"死亡"状态，多次死亡按**每次死亡**各爆一次，`rosterState` 同规则回退。
  **生效前提**：随包 WASM pin 需升级到含上游 `6d513d1` 的版本（当前 pin `v0.4.7` 未包含，上游该提交
  已进 main 但尚未发版）——在此之前字段缺省 = 死亡终态，行为与既往逐位一致（前端改动完全由证据开关）。
