# Android 3.14.2

- versionName：3.14.2
- versionCode：3014002
- 变更等级：patch。装甲查看器的显示调整：手机/网页的相机 FOV product 整体乘 1.1，并把远距斜率/上限从 +0.0128/m、2.8 提高到 +0.028/m、3.8，车体随距离缩小更明显（30m 约 -14%，100m/500m 约 -35%）；横屏粗指针手机改用平板式浮层布局，并解除竖屏的 420px 最小高度。竖屏手机布局不变。WebGL 上下文丢失现在会显示带 GPU 信息的错误态，并可“重试”重建 renderer。
- Native Bridge：保持 v3，RPC、本地 origin 和通信契约不变；`contracts/android-native-bridge.json` 不改。
- 强制更新：`ANDROID_MIN_SUPPORTED_VERSION_CODE` 抬到 **3014002**（= 本版本 versionCode），所有低于 3.14.2 的客户端强制更新；这是用户指令的 patch 例外延续（3.14.1 门槛 3014001 → 3014002）。3.14.1 不再 publish（3014001 < 3014002，会被 floor guard 拒绝）。

3.14.1 已取得 immutable release identity（staged），不能复用来承载新的 bundled frontend；
本候选从 3.14.1 递增至 **3.14.2 / 3014002**，只声明新的候选版本，不代表已 stage、已真机验收或已发布。

# 显示调整

相机保留 Armor Inspector 15 m / 18.75° 作为曲线定义参考与近距 40° 上限，但生产显示 profile 整体乘 1.1：实际 15 m 默认 FOV≈20.59°，车体比 18.75° 参考小约 9%；远距斜率/上限改为 `0.028/m`、`3.8`，30 m 比 15 m 约小 14%，100 m/500 m 约小 35%（100 m 起封顶）。该 profile 对 Web 与 APK 共用同一份 frontend 源码，因此网页版同步生效。

横屏手机/粗指针平板（`pointer: coarse` + `orientation: landscape`）改用与平板/桌面相同的左上信息卡 + 四角浮层布局，信息行压成单行；不再套用竖屏 mobile 的上下窄带，也没有额外的 height 断点。同时解除 `.armor-view` 的 420px 竖屏最小高度。竖屏手机（含原 390×844 / 360×640 场景）保持既有布局。

# 验证

- `AgentArmorView.dom-contract.test.js`：相机常量/调用与 `dollyZoomFov` 距离缩放 profile 断言；context-lost 监听/GPU 标签/retry 重建守卫。
- `browser-armor-mobile.mjs` 新增 `armor-740x360-landscape-coarse`、`armor-1024x768-landscape-tablet-coarse` 与 `armor-context-lost-init`：真实浏览器断言横屏粗指针手机/平板走平板式布局、触控目标与无横向溢出，并验证 context lost 错误态不会被后续 loading/ready 覆盖、retry 重建 renderer。
- `browser-armor-shot-readiness.mjs`：15m 命中视角按 1.1 显示 profile 断言 20.59°（18.75° 参考），overview 仍 50°。
- 3D 画面本身仍由用户真机验收；本候选不把模拟器结果当真机证据。

# 已知未修 / 不在本次范围

- LDPlayer/雷电等模拟器上的 GeckoView WebGL context lost（`glGetGraphicsResetStatusKHR` 未实现）仍无法渲染；本次只把它变成明确的错误反馈，不声称模拟器兼容。
- 真实 GPU reset 的恢复依赖上面的 retry 重建 renderer；如果驱动持续重置，重试仍会失败。

本候选继承 [3.14.1](3.14.1.md)；后续 stage、真机验收与 publish 仍按发布规程分别执行。
