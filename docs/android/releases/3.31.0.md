# Android 3.31.0

- versionName：3.31.0
- versionCode：3031000（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：minor（手机底部导航改为 5 Tab）
- 最低支持版本：3017007（沿用当前生产门槛，不变）。

## 说明

- **底部导航**：手机底部固定为回放、名人堂、百科、联赛、更多 5 个 Tab，不再横向滚动。
- **更多页快捷入口**：科技树、地图、联赛直播回放和 bilibili 推荐移到「更多」页顶部。推荐目录没有内容时不显示推荐入口。
- **横屏与平板**：矮视口横屏和平板的图标栏按战斗、资料、赛事、社区分组，各分组之间用分隔线隔开。
