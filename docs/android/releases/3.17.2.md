# Android 3.17.2

- versionName：3.17.2
- versionCode：3017002（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：patch

新版本的 Native `AgentAssetProxy` 直接从 `https://assets.wotbtools.com` 获取 3D 与 2D 在线资产。本机 `/agent-assets` 路由、ETag 磁盘缓存、条件请求与 stale-cache fallback 保持不变。

旧 APK 继续按其编译时 origin 请求资产；Tencent COS 与 TX legacy `/agent-assets` 兼容代理暂时保留给旧客户端和回滚。该版本不改变 Native Bridge wire contract，也不要求抬高最低支持版本。
