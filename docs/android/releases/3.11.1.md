# Android 3.11.1

- versionName: 3.11.1
- versionCode: 3011001
- Native Bridge: v3, unchanged
- Version classification: patch — bundled replay playback and map-asset loading fixes. `android-v3.11.0` already has an immutable tag/source identity, so this candidate uses the next patch version.
- Minimum supported version: unchanged at 3000000.

This candidate ships the **frontend side** of the AoI entry work: turret, gun and hull-roll grid columns are sampled only inside the protocol-accurate visibility window, so a brief hidden gap can no longer slide the old turret angle into the new one; the 3D and 2D views share the same projection. Tank hit/armor anchors keep the client's original 0.02 s reset semantics.

The hull `pose_kf` display reconstruction (10 Hz history, steady 0.2 s latency) is **not** delivered by this candidate: the pinned Agent `v0.4.9` / `8dcec2c` still emits the original hold-jump keyframes, and `deploy/agent/source.json` is unchanged. With this pin the hull keeps the client's entry staircase. The smoothing becomes effective only after a later upstream Agent release plus a WotbTools pin bump (including artifact and AI projection-golden synchronization); do not advertise it as an APK capability before that pin lands.

Map loading is now fail-closed: incomplete terrain metadata (including null/false/empty numeric bounds) falls back to the 2D map instead of decoding a mis-scaled height field, asset 404/parse failures are surfaced as a non-blocking degradation banner, and sky/alpha-blend/variant semantics come from `scenery.glb` material extras rather than node-name guesses.

The Agent WASM pin is unchanged (`v0.4.9`); this patch ships frontend changes only. Backend rollout is not required for old APKs. This source candidate does not establish staging, device acceptance or production publication.
