# Android 3.15.3

- versionName：3.15.3
- versionCode：3015003（由 `wotbVersion` 推导）
- 变更等级：patch（用户于 2026-10-20 明确裁定的本次例外）。修复现有装甲查看器的共面求交精度、姿态同步与微动点击问题。虽然会纠正判定结果，用户将此次影响有限的边缘场景作为 patch 处理；不改变中大型判定错误一般按 major 发布的规则。
- 本次判定修复进入 APK 的 bundled frontend，因此在 main 的 3.15.2 上递增版本，继承其推荐卡片等已有改动。
- Native Bridge 保持 v3。用户随后明确要求本次 patch 也强制升级，因此最低支持门槛由 `3014002` 抬到 `3015003`；该例外仅适用于本候选。
- Minimum supported version: raised to 3015003 (3.15.3).

修复 Kranvagn 等共面炮管／炮盾在跳弹续飞时漏算模块，导致热力图出现随机绿紫或红绿噪点的问题。CPU、GPU 与点击续飞统一使用最近主装甲的浮点误差窗口，并处理跨网格候选、重试失败后的姿态恢复及点击微动。

验证包括相关单测、真实 GLSL 回归、Web 浏览器门禁及用户对残留噪点的实机 Web 验收。复现与证据见 [#711 修复记录](../../research/armor-heatmap-711.md)；这些结果不替代 Android APK 的构建与真机验收。

本文件仅声明发布候选。合并后的 stage 成功、Android 真机验收通过并显式 publish 后，才更新线上发布清单。
