## 说明

- **手机横屏导航改左侧图标栏**：触屏横屏矮视口（高度 ≤520）不再渲染顶栏与底部
  Tab 栏，导航收进左侧图标栏，右侧内容区获得完整高度；回放工作区沉浸态仍隐藏
  全部导航。
- **射击结果卡缩小**：紧凑档字号、行高与内边距再降一档，最大宽度 420 → 360px，
  减少竖屏/横屏对 3D 画面的遮挡。
- **贴边抖动修复**：结果卡避让固定 UI 时按左右可用空间选边，不再按卡片中心
  逐帧比较，相机阻尼下贴边不再左右翻转。
