# Android 3.5.0

- versionName: 3.5.0
- versionCode: 3005000
- Native Bridge: v3, unchanged
- Version classification: minor — the bundled frontend adds an administrator-maintained bilibili creator directory with manual star ratings and optional site-owned thumbnails.
- Minimum supported version: unchanged at the existing 3.0.0 major floor; this minor feature does not introduce a forced-update requirement. Publication still compares the candidate major with the actually published version under the existing release guards.

The primary navigation alongside League standings and broadcasts opens creator recommendations. Visitors can browse recommendation categories, creator profiles, optional assessments, recommendation scores and bilibili homepage links. Tournament administrators maintain unique Bilibili UIDs, categories, assessment levels, one-to-five whole stars and optional COS avatars. Images are submitted with the form and normalized to a longest edge of 256 pixels; they have no uploader-account ownership. The catalog includes no favorites or voting pool.

This candidate follows the merged 3.4.0 tournament CSV import and 3.4.1 broadcast-navigation update and retains both. Deploy the backend migrations and API before accepting the client. The shared COS runtime credentials and separate creator-avatar namespace are described in the feature documentation. Native RPC, authentication and runtime origin are unchanged.

This document records the source candidate only. It does not assert a staged APK, device acceptance or production publication. Those remain separate release-workflow steps, including comparison with the actual published major version when applying the minimum-supported-version policy.
