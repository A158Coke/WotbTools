# Android 3.0.2

- versionName: 3.0.2
- versionCode: 3000002
- Native Bridge: v3 (unchanged)
- Version classification: patch — close the mutual exclusion gap between web downloads and native file/folder pickers.
- Minimum supported version: 3000000. Publishing this candidate from 2.x inherits the unpublished 3.0 major cutover obligation; same-major patch publication does not raise the floor.

Once a web download starts, file and replay folder pickers are rejected until spooling, document selection and destination writing finish. A download requested while a file/folder picker is active is rejected before spooling and its response body is closed. A later picker can no longer cancel an already accepted download.

Real-device acceptance must cover opening file/folder pickers during a large download, downloading while a picker is active, and retrying after cancellation, failure and successful save. The Gecko acceptance checklist in `docs/android/release-process.md` still applies; staging and publication remain separate steps.
