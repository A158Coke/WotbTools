# Android 3.14.3

- versionName：3.14.3
- versionCode：3014003
- 变更等级：patch。PR #699 修复手机端多场回放的 BattlePicker 底部 sheet 被 AppTabBar 遮挡/截断问题；该修复位于随 APK 打包的 bundled frontend，因此不能复用已取得 immutable release identity 的 3.14.2 候选。
- Native Bridge：保持 v3，RPC、本地 origin 和通信契约不变；`contracts/android-native-bridge.json` 不改。
- 强制更新：不新增门槛抬升。`ANDROID_MIN_SUPPORTED_VERSION_CODE` 保持现有 **3014002**；3.14.3 只是新的 patch 候选，不因本次 UI 修复自动强制 3.14.2 用户升级。

# 变更

- 手机端（<768px）BattlePicker 的 scrim/sheet 在 compact 模式 Teleport 到 `body`，越过 Replay Workspace 的局部 stacking context，避免被根层 `AppTabBar` 覆盖。
- 修复 Teleport 后的 lifecycle：KeepAlive deactivation 时主动关闭 overlay；Data capability 被 `v-show` 隐藏时通过 owner visibility 信号关闭，避免 sheet 残留到其他页面。
- 保持 desktop anchored dropdown、outside-click、Esc、键盘/ARIA 行为不变，并补 mobile/KeepAlive/capability hidden 回归测试和真实浏览器触摸路径。

# 发布说明

`android-v3.14.2` 已固定到旧源码身份，不能承载 #699 的新 bundled frontend。3.14.3 是 #699 合并后的 Android 候选版本；stage、真机验收和 publish 仍按标准 Android 发布流程执行。
