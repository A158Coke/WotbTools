# Android 3.9.0

- versionName: 3.9.0
- versionCode: 3009000
- Native Bridge: v3, unchanged
- Version classification: minor — add collapse/expand controls for the 3D playback toolbar in the APK-bundled frontend.
- Minimum supported version: unchanged at 3000000 (3.0.0 floor); this optional feature does not require a forced update.

The lower 3D playback toolbar now has a collapse/expand button at its upper-right corner, with a minimum 44px hit target and Chinese, English and Russian labels. Collapsing closes the Display panel and leaves only the restore button. Playback, time, speed, camera and vehicle selection continue unchanged. A new replay file restores the expanded toolbar; fullscreen and viewport changes preserve the disclosure state.

This candidate builds on 3.8.1. The existing immutable android-v3.8.1 tag identifies the previous source commit, so the changed bundled frontend requires a new candidate identity. The toolbar is a small user-facing feature, rather than a bug fix, hence 3.9.0 instead of a patch increment. There are no Native Bridge wire changes or new minimum-version requirements.

Staging, real-device acceptance and production publication remain separate release steps. Before publication, verify toolbar collapse/restore on a real device in portrait, landscape and fullscreen, including continued playback and retained camera/selection. This release note does not claim that the candidate has been staged or published.
