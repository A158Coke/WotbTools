# Android 4.5.0

- versionName：4.5.0
- versionCode：4005000（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：minor（坦克百科新增 XI 初始/满级配置与互斥技能选择；复用参数计算、装甲和模型加载链，不涉及 Native Bridge、后端 HTTP 契约或 Agent WASM pin 变更）
- Minimum supported version: unchanged at 4001000 (4.1.0).

## 说明

- 具备有效客户端升级数据的 XI 车辆可切换初始与满级配置；满级按真实升级节点及技能互斥组投影参数、弹药、装甲与俯仰范围。初始配置保留技能选择但不应用升级效果，现有乘员技能保持独立。
- 配置进入页面链接和前后导航；装甲查看器的射手与受击方分别保留升级和技能状态。普通车辆及未提供升级参数的旧链接保持原有行为。
- 缺失升级规则时明确提示数据不可用，不推算升级数值；没有独立阶段模型时沿用资产包已有模型，不能据此认定初始与满级模型差异已验证。
- Web bundle 随 APK 打包，因此递增 Android 源码版本；不抬升最低支持版本，不增加强制升级要求。版本说明不代表 APK 已构建、stage 或 publish。

## 验证边界

- XI 升级字段来自客户端定义及上游资产导出；功能依赖资产包实际提供匹配的升级数据。前端适配不自动发布上游数据或模型。
- 本地确定性夹具的交互和计算验证不代表真实 XI 公网 detail/GLB 或实车视觉验收；真实模型、装甲显示与俯角需要在匹配资产上人工核对。
