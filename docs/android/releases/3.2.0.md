# Android 3.2.0

- versionName: 3.2.0
- versionCode: 3002000
- Native Bridge: v3 (unchanged)
- Minimum supported version: unchanged at 3000000 (3.0.0 floor).
- Version classification: minor — two runtime changes inside the bundled stack. (1) The WASM pin rises to
  Agent v0.4.8 (`deploy/agent/source.json`: ref `a76ea7b36fa841f8e3c671a0bc93ec5b1aa6705f`,
  asset `wotb-replay-wasm-v0.4.8.zip`, sha256 `67ceb8b8…69e7`, verified against the GitHub release digest
  and the downloaded bytes): the respawn death/resurrection tracks become available and the upstream
  damage-attribution fixes take effect. (2) The bundled frontend's playback runtime changed: 2D pose now
  shares the 3D scene's channels and freezes when the vehicle leaves view, markers render at their true
  position, the 3D ground uses the contract `ground.webp` for every quality tier, and OTA basemap swaps
  require a matching world-bounds/orientation declaration. No HTTP or Native Bridge wire changes, no
  feature removal, no new permission.

Unpublished candidate at the time of writing (not staged, not published); the record below is the change it
carries, and staging still requires the documented stage → on-device verification → publish flow.

This candidate builds on the committed 3.1.0 (global default tournament rules) and inherits it.

What changes for users:

- **2D 回放位姿与 3D 同源**：车辆位置/朝向取同一份通道（`pose_kf` 关键帧优先），失去视野后图标停在最后
  观测点（不再跟随客户端滤波器的预测延续），重新被点亮时从新位置继续。
- **标记严格落在真实位置**：此前"防重叠推开 + 虚线回指"的 2D 布局删除，密集区域允许图标互相压盖
  （与 3D 一致）；名牌 / 血量块的防重叠不受影响。
- **地面贴图四档统一**：最低画质档不再使用客户端 HUD 小地图（它覆盖约 620 m、多出外围一圈），四档
  都用 ±300 契约底图，与 2D 地图同框。
- **OTA 底图更严**：远端底图换图前必须声明并通过世界框/取向/像素尺寸校验，任一不符即回落包内
  （旧 schemaVersion 1 索引一律不换）。
- **复活模式生命状态（#622）已生效**：随包 WASM pin 已升至含上游 `6d513d1` 复活轨道的 v0.4.8——
  复活模式的车辆复活后不再停在"死亡"状态，多次死亡按**每次死亡**各爆一次，`rosterState` 同规则回退。
  （字段缺省的旧产物仍是"死亡终态"，行为与既往逐位一致。）
- **伤害归因修复（上游 v0.4.8）**：`shots[]` 伤害直读服务器 method8 结算值、归因确定性化（配不上 →
  0 + `dmg_unattributed`，fail-closed），HP 链降为无结算值时的兜底。上游 22 场对账中伤害 3 处 / 归属
  5 处变化、皆为修正；本仓重生成的 3 个 ai-projection golden 里 `battle`/`projection` **逐字段不变**
  （6 处差异全部是 `projection.engine` 的 provenance：commit + release），即这三份 fixture 不受影响。
