# Android 2.2.4

Android 2.2.4 is a patch release for the app navigation contract.

- The APK has no standalone Home destination. Replay is the Android landing page and the first bottom-navigation item.
- The Android bottom navigation is `Replay · Hall of Fame · Tankopedia · Tournament Points · More`.
- Stale Android `?view=home` links are canonicalized to the Replay-root URL while unrelated query parameters and hashes are preserved.
- Logout/session-loss returns to the runtime default destination: production Web goes to Home, while Android and local Web go to Replay.
- Public Web Home behavior is unchanged.

Version authority remains `android/gradle.properties`: `2.2.4` maps deterministically to versionCode `2002004`. Native Bridge remains v2; this patch does not change the bridge contract.
