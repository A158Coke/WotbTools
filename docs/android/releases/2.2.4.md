# Android 2.2.4

Android 2.2.4 是 App 导航契约的 patch release。

- APK 不存在独立首页；回放工作台是 Android 落地页，也是底部导航第一项。
- Android 底部导航为 `回放 · 名人堂 · 坦克百科 · 联赛积分榜 · 更多`。
- Android 中遗留的 `?view=home` 会被移除，同时保留无关 query 与 hash；根路径因此回到 Replay，`/download/android`、`/sponsor` 等 path-owned 页面继续由各自路径决定目标。
- 登出 / 会话失效回到当前 runtime 的默认落地页：production Web 回首页，Android 与本地 Web 回回放。
- Public Web 首页行为不变。

版本权威仍为 `android/gradle.properties`：`2.2.4` 确定性映射到 versionCode `2002004`。Native Bridge 保持 v2，本 patch 不修改 bridge contract。
