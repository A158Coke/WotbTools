# Android 2.3.1

- versionName: 2.3.1
- versionCode: 2003001
- Native Bridge: v2 (unchanged)
- Minimum supported version: unchanged at 2003000 (2.3.0).

Patch release for 3D replay terrain alignment in the shared frontend. The terrain heightfield was drawn one heightmap texel (span/512, 1.17 m on 600 m maps) off along the mirrored map axis on every map, so retaining walls facing that way showed a 1–2 m earth slope in front of them that the game client does not have. The frontend now decodes the heightfield in the engine's own vertex layout (old asset packs are corrected at load; packs stamped `terrainLayout: 2` are used as-is), which also re-aligns vehicle ground height, hull pitch/roll, aim occlusion and the water shoreline fade with the scenery. 2D replay is unchanged. Builds on 2.3.0. Stage builds and verifies the immutable APK and evidence; production version.json changes only through a separate publish run.
