# Android 3.27.1

- versionName：3.27.1
- versionCode：3027001（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：patch（地图预览封面统一 + 2D 底图升级，加载提速）
- 最低支持版本：保持现有发布配置，不因本版本抬升。

## 说明

- **封面统一 cover.webp**：3.25.0 的地图预览里，未收录打包 2D 底图的 14 张图（矿井阵地、
  变体空间、老版复刻等）封面回退用的是 `ground.webp`（4096²、3–4MB/张），且与另外 29 张的
  打包战术底图风格不一致。现全部 43 张统一为 `cover.webp`（512²，与 2D 战术底图同一调色管线，
  ~100KB/张）：选图网格封面流量 42MB → ~1.5MB，来源与风格一致。
- **未收录图 2D 底图升级**：那 14 张图的 2D 模式底图从 `ground.webp`（4096²、3MB）换成
  `map2d/<key>.webp`（canonical 1254² 校准战术图，~900KB，worldBounds ±300 契约框）——
  加载提速，风格与另外 29 张一致。
- **标注导入导出跨视角**：导出文件不再区分 2D/3D（同一张地图即可互导），合入前旧导出
  （`-2d`/`-3d` 后缀）仍可导入。
- **不变的部分**：回放工作台五能力、地图预览的 3D 场景与绘制功能、装甲查看器与录像者视角
  的行为与之前相同。
