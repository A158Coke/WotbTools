# Android 5.7.0

- versionName：5.7.0
- versionCode：5007000
- minor 版本：**新增** 3D 回放战场快捷标记呈现（上游 v0.5.4 `markers` + v0.5.3 `attention_to_cell`）：`moving_here` 贴地 ping（圆环+20m 高光柱，炮线亮色）、`attack`/`ally_retreat` 目标车辆光环（友军亮绿 + 出现闪烁 2.4s，跟随位姿）、`attention_to_cell` 注意扇区地面高亮（半透明面 + 2.5m 贴地描边带 + 出现闪烁；九宫格语义档案区域并集，与 2D 概览同一聚合，缺档 fail-closed）。来源卡与坦克名牌同一 DOM 卡片（屏幕空间恒定大小、不随距离缩放），身份两行 = 标注来源；目标类卡（attack/ally_retreat/attack_enemy）在目标环上方以**单行**标注「发起者 要求攻击/要求撤退 目标车型」（整体上移 60px 避让目标自己的血量/ID 名牌），help 族（help_me/help_me_ex/follow_me/support_me_with_fire）在发起者位置出琥珀 ping + 发起者卡；名册血量条改为整行长度（填充铺满条目，数值保留行尾原位）；回放工作台改版：2D/3D 合并进同一面板（头部切换），事件流始终展开在面板下方、向下自然延伸（不占窗口高度），2D/3D 切换同步播放进度/播放状态/倍速（进度条共用同一份状态），播放条移出播放窗口、dock 在窗口下方通栏；其余快捷指令与聊天正文在左下滚动流展示（与事件流同一行文案与身份纪律）。生命周期为回放时钟窗口状态（下发后常驻 10 战斗秒、暂停冻结、倒带重现、末段淡出）。Display 面板新增「战场快捷标记」开关（`wotb.pb.marker-prefs.battleMarkers`，默认开）。事件流数据面不变（WASM pin 仍 v0.5.4，无 Agent 侧改动）。3D 名册卡片高度缩到车道的 2/3（血条仍铺满整行）。回放内车辆名牌 HP/装填条、HUD 左右队伍血条与名册行血条统一为矩形（无胶囊圆角）。3D 地面草层暂时关闭（用户报障分布待核查；`GRASS_LAYER_ENABLED=false`，草数据面与预算不变）。
- Native Bridge：v4，最低支持版本保持 5004001（minor 不抬门槛）。

本条记录候选功能；真机布局与视觉验收在实际设备确认后补充。
