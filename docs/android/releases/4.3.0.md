## 说明

- **移动端 2D 地图预览布局**：手机形态下地图吃满可用宽度并水平居中，工具区紧随地图（不再有「舞台吃剩余高度」造成的大块空白）；装不下时页面合理滚动。桌面布局不变。
- **右上角全屏入口**：Map Preview 2D/3D、Replay 2D/3D 四个视图统一在画布右上角浮动按钮进入/退出全屏（手机形态）；Replay 传输条在手机形态不再出现第二个全屏按钮，桌面保持原位。全屏不重建场景、不丢相机/时间轴/标注/选中。
- **移动端单指相机契约**：3D 场景在手机形态下——自由模式单指拖动 = WASD 式贴地平移；固定（原「沙盘」）模式单指拖动 = 绕地图中心旋转；**双指不再承担任何相机控制**（取消 look/pinch 分类，也不再有误判缩放）。桌面鼠标/键盘/滚轮行为不变。
- **竖向距离滑条**：3D 视口右侧、全屏按钮正下方，上近下远、竖直拖动立即改变真实相机位置、松手停住不回中；值由相机真实状态反推，FOV 不变。Follow/录像者视角下不出现。
- **教程与文案**：镜头模式「沙盘」更名「固定」；3D 引导文案解释单指平移/固定旋转/右侧竖条/右上角全屏；Map Preview 2D/3D 增加页面级操作提示（此前无任何教程入口）；三语同步；教程 contentRevision 6 → 7（不重发核心引导）。
- 新增 `test:browser-map-preview` 真实浏览器几何门禁（手机竖屏四档 + 手机横屏 + 桌面回归）。
- Web bundle 随 APK 打包；Agent WASM pin 不变。发布说明在发布时归档。
