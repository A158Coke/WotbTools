# Android 3.12.0

- versionName: 3.12.0
- versionCode: 3012000
- Native Bridge: v3, unchanged
- Version classification: minor — add optional broadcast start times and separate viewing/input time-zone selectors, alongside terminology corrections.
- Minimum supported version: unchanged at 3000000; no forced update.

Broadcast lists default to the event server's time zone and allow a viewer override, with daylight-saving offsets determined by the recording date. Administrator date/time input defaults to UTC+8 and offers explicit offset choices. Known instants are stored in UTC; records without a specific time keep their original date-only precision. Group numbers are optional and omitted from the display when absent; supplied numbers retain the existing category ranges.

Tournament management uses Tournament rather than Season; qualification uses Prove Your Skill / Путь мастерства. Top 8 and Top 4 describe complete stages. Chinese perspectives display 个人视角 and 观战视角. Existing v1/v2 response shapes remain compatible; new timed category/replay operations use v3 over the same business services.

V41 corrects the unchanged seeded event name to Blitz Professional Cup (BPC), preserving administrator names and replay facts. V42 adds nullable start instants without guessing historical clock times. V43 adds 71 evidenced 2025/2026 broadcasts across 19 regional tournaments, preserving administrator data and skipping ambiguous ownership or incompatible existing root formats. Stream start supports the calendar date only; this batch does not invent battle clock times. Clearing a clock time retains the unedited server match day. Staging, device acceptance and production publication remain separate release steps.

Initialized event names provide Chinese, English and Russian values; replay titles are concise Chinese/English labels. Original names and video titles remain in research evidence. V44 localizes unchanged defaults, including the three earlier CN replays, while preserving administrator edits. This is a data correction with no new UI fields or Native Bridge changes.
