# Android 3.7.0

- versionName: 3.7.0
- versionCode: 3007000
- Native Bridge: v3, unchanged
- Version classification: minor — content-based visibility for the existing creator directory, with no breaking wire or runtime change.
- Minimum supported version: unchanged at the existing 3.0.0 major floor; no forced update for this minor release.

Anonymous and ordinary signed-in visitors see only populated creator categories. An empty directory hides its primary navigation entry; direct links show a not-yet-published notice and retry. Administrators retain empty categories, the directory and management entry so they can create the first creator. The existing collapsible filter, manual stars and optional site-owned avatars remain.

Visibility refreshes on load, focus, reconnection, explicit refresh and successful management writes. Failed reads preserve the last successful public snapshot. The backend advertises the populated-category capability separately; older backends still support administration while public visibility fails closed. Older APK bundles require this frontend update to hide their navigation entry, but their existing APIs remain compatible.

This is a source candidate, not evidence of APK staging, device acceptance or production publication. Existing immutable-identity and release guards apply before stage/publish.
