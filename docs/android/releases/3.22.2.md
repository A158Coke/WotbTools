# Android 3.22.2

- versionName：3.22.2
- versionCode：3022002（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：patch（3D 回放俯视相机恢复持续总览模式 + 回放视窗打开时自动垂直居中）
- 最低支持版本：保持现有发布配置，不因本版本抬升。

## 说明

- **俯视相机**：恢复为持续的总览模式——OrbitControls 以**地图中心**为旋转中心，拖拽 / 滚轮围绕地图中心旋转与缩放；极角上限挡在地平线以上，相机点按地形净空校验。相机档位选择为 `自由 / 俯视 / 录像者`，控制条上的「俯视」按钮是快捷对心入口。默认以俯视进入，仍在俯视时换回放会重新对心到新地图中心。
- **回放视窗居中**：打开 2D / 3D / 射击 / AI 视图时自动把当前视窗垂直居中（视窗高于视口时对齐顶端）；懒加载 chunk 就绪后只定位一次，切走即撤销，不覆盖用户之后的滚动位置。
- 不改变匿名采集字段、个人身份或原始回放的隐私边界。
