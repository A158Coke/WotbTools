- patch 版本：装甲厚度视图交互与外观：
  - 厚度模式点击先失效在途判定（递增判定代数，丢弃异步响应），再清轨迹、命中点与 HUD 本发距离；点选卡只显示本次点击的装甲读数，旧命中点不再残留；

  - 选中高亮保持原色、不透明并写深度，未选中装甲板 0.18 / 模块 0.15、隐藏勾线；切换动态装甲状态时若选中仍有效则重放高亮，失效选择自动清卡/复位；5 档色阶阈值、判定链、热力图与结果卡行为不变。
