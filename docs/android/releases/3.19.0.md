## 说明

- **局内定时消耗品状态徽标**：2D/3D 回放中，车辆名牌的**血量条左侧**显示
  **正处于激活窗口**的定时主动消耗品：客户端道具图标（32px 环内居中、20px
  图标）+ SVG 剩余时间环。冷却、瞬发消耗品、未使用、已就绪、状态未知以及
  **身份未闭合的线码**一律不渲染（fail-closed）；离开 AoI 的未知段与重入后的
  旧状态都不复用，环按名牌既有 10Hz 节拍推进，
  不逐帧驱动界面层。
- **装载解码升级**：Agent 引擎 pin 升到 v0.4.19（0x3F = Shell Reload Boost 补入闭合表）。Type5 物化尾部按「3 消耗品 + 0..3
  配件 + 能力」的 7 条描述符解码（不再要求满 9 件），Type32 消耗品事件带
  `durationSec` / `endsAt` / `everActivated` / `slot`，前端据此得出剩余时间与冷却态；
  配件 ID 走 9 位挂件串。
- **物品映射修正**：0x49 按 `provisions.pb` id 106 归为小份食物（SMALL_FOOD），
  与 Java 旧映射的差异以 pinned correction 冻结在 golden 中，只放行该字段。
- **AI 投影 golden**：随 pin 仅刷新 provenance（`agentRelease` / `agentCommit`），
  battle / projection 数据逐字段不变。
