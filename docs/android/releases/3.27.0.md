# Android 3.27.0

- versionName：3.27.0
- versionCode：3027000（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：minor（3D 回放新增开镜穿深着色；Agent WASM pin 升级到 v0.4.22，随 web bundle 进 APK）
- 最低支持版本：保持现有发布配置，不因本版本抬升。

## 说明

- **开镜穿深着色**：3D 回放性能选项新增「狙击镜穿深着色」，录像者开镜时按当前弹种给准星所指敌车的装甲着色。默认关闭。
- **引擎 v0.4.22**：提供弹种时间线 `author_shell_timeline`；接收突发的时间轴重建扩展到全部车辆，网络停摆后炮塔跳变和远程车猛冲会消失。
- **给养修正**：瑞典大小补给不再标反，`0x4C`/`0x4D` 不再当食物显示。
- **共享装甲渲染**：装甲查看器的板分类与穿透场景构建搬到共享模块，判定规则不变。
