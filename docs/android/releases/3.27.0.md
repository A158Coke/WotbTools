# Android 3.27.0

- versionName：3.27.0
- versionCode：3027000（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：minor（3D 回放新增开镜穿深着色，随 web bundle 进 APK）
- 最低支持版本：保持现有发布配置，不因本版本抬升。

## 说明

- **开镜穿深着色**：3D 回放性能选项新增「狙击镜穿深着色」，录像者开镜时按当前弹种给准星所指敌车的装甲着色。默认关闭。
- **依赖新引擎产物**：弹种时间线来自 Agent 的 `author_shell_timeline`。产物缺这个字段时即使打开开关也不显示，其余 3D 回放不受影响。
- **共享装甲渲染**：装甲查看器的板分类与穿透场景构建搬到共享模块，判定规则不变。
