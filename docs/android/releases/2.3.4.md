# Android 2.3.4

- versionName: 2.3.4
- versionCode: 2003004
- Native Bridge: v2 (unchanged)
- Minimum supported version: unchanged at 2003000 (2.3.0).

Patch release for 3D replay vehicle models in the shared frontend. Fixed-casemate tank destroyers (T110E3, ISU-152, T28, SU-85, StuG III G, Hetzer, SU-122-44, E 25 and the rest of the 44/735 exported fleet) have no `turret_N` node in the client source model, so the scene rejected their whole GLB and kept the box proxy for the entire battle. The scene now mounts the model whenever the `model_origins` pivot chain and a gun node group exist: the turret-traverse stream is written to the gun group around the track+turret pivot (with the initial-rotation compensation) and gun pitch around the gun origin, matching the client's "TD turret = gun mount traverse" presentation; rotating-turret vehicles are unchanged. A model with neither turret nor gun nodes still falls back to the proxy (fail-visible). The detached-turret playback from 2.3.3 stays consistent for these vehicles: when a detached-turret track exists, the flying assembly is built from the selected gun node group instead of dereferencing the absent turret node. Builds on 2.3.3 and retains its terrain json/bin pairing. Stage builds and verifies the immutable APK and evidence; production version.json changes only through a separate publish run.
