# Android 2.2.7

- versionName: 2.2.7
- versionCode: 2002007
- Native Bridge: v2 (unchanged)
- Minimum supported version: unchanged at 2002002 (2.2.2).

Bundles the shared frontend changes for destroyed vehicles in 3D replay: replay-clock-driven charcoal wreck materials, short irregular flames, fewer sparks and staggered smoke puffs, and authoritative death-triggered explosions even when kill attribution is unavailable. Rewinding restores the original material state; seeking does not replay historical explosions.

This is a patch release with no Native Bridge breaking change. Stage builds and verifies the immutable APK and evidence; production version.json changes only through a separate publish run.
