# Android 5.8.0

- versionName：5.8.0
- versionCode：5008000
- minor 版本：新增「版本变更」总览页（`?view=agent-version-diff`）：
  - 对比相邻主线 dataset（当前 `11.21.0 → 11.21.0_1 → 11.22.0`）的坦克参数、装甲、研发、物品与地图差异；
  - 版本页使用坦克百科的车名、车型、国籍底图和封面裁剪；金币/收藏车名与百科同一套配色（金币黄/收藏蓝，premium 优先）。新车卡显示关键性能，正文按地图、装甲及参数变化呈现，研发、物品和技术记录收在页尾。地图保留两版底图滑杆，逐车参数直接展示旧值、新值与差额。装甲查看器的厚度模式改为**连续渐变**着色（锚点沿用击穿语义色与 30/60/100/200mm 阈值线性插值，<30mm 标定绿、≥320mm 深红平段，绝对域——同一厚度在任何坦克同色；替代 5.7.5 的 5 档固定色阶）。**数据条目名与坦克百科参数面板同源**（`agentTanks.params.*`：装填时间、每分钟伤害、平均穿透/伤害、瞄准时间、车重、极速、视野、转速、隐蔽等，三语齐全），配置级裸字段（`reload_time`/`dpm`/`aim_time`/`standard_damage`…）与「研究」子树的模块统计（`gun:<名>.stats.reloadTime`、`hull.hp`、`bbox.*`、`invisibility.moving`、`tags` 等）均显示百科同款条目名，不再回显代码字段；装甲章节内嵌双版本厚度视图沿用装甲查看器的连续渐变厚度色和 `MeshBasicMaterial` 平涂，**展示炮管与履带**（模块网格口径同查看器；**默认相机距离比"刚好装下"近一半**，滚轮可拉远）。对比滑杆整合在画面分割线上（拖拽手柄/键盘步进/角标一键切单版）、默认整面突出有改动的装甲板，其余板面淡化，**每块改动装甲面一条旁注 + 引线连到其相机可见表面**（引线端点逐帧取板件表面朝向相机的最近采样点），旁注只标厚度变化（`旧值 → 新值 mm`；单侧存在标 `+新值`/`−旧值`，间隙标类别；**点击画内旁注或文字行可突出对应板、淡化其余**）；旁注与引线由场景内 2D 叠加画布逐帧绘制（与 WebGL 同帧同步，旋转/缩放零延迟）；**装甲文字行可点击**——点选后在对比器里突出对应板件、其余装甲与模块网格淡化到几乎透明（opacity 0.18/0.15 + 不写深度，与装甲查看器厚度模式点击板件的隔离数值一致），未选中板件的旁注与引线同步淡出，点击画面其他位置恢复默认板面高亮；**装甲改动文字明细默认收起**（点「改动明细」展开）；装甲文字版完整展示六向、板件（含配置级火炮/炮塔板件与间隙增删）、结构装甲与履带变化；
  - 数据来自 WoT-Blitz-Agent 的 `/diffs` 静态通道（`index.json` + 每 pair 的 `summary.json` / `tanks/*.json` / `maps/*.json`），页面会回读 `/v/<id>/version.json` 校验 release；
  - 「版本变更」是电脑侧栏与手机菜单的第一项，紧接「数据版本」。入口使用与其他栏目一致的文件差异图标。窄屏为单列布局，分割滑杆含 44 × 44 CSS 像素触摸区。新车参数、逐车差异和装甲厚度复用坦克百科的数值与单位排版。地图和装甲共用分界线滑杆与版本切换，视觉手柄在两端继续与分界线对齐。
  - 参数总览和火力详情按两版导出的炮塔/主炮局部 ID 去除整车摘要中的顶配重复项，分别保留近穿与远穿、整车与车体生命值。炮管仰角按导出下限取反，俯角按上限显示，车头与车尾扇区的角度、覆盖角和过渡角各自以度显示。
  - 装甲卡片的车名与封面打开新版坦克百科详情，版本对选择器支持键盘与触控。双版本装甲引线使用深色外描边和浅色线芯，默认及选中标注使用不透明深色底板。聚焦单板时，其余标注、文字与引线整层按 30% 不透明度叠加，点空白恢复全亮。
  - 全站主要内容卡片共用四季主题：冬季雪景上的科技树容器为 40% 白色，坦克及内容卡片为 94% 白色。科技树使用蓝灰色连线、细滚动条和磨砂等级栏。春、夏、秋沿用相同层次，底色分别使用原季节的深绿、暖金棕和暖褐。
  - 参数调整的差值读取目标版百科规则，改善为绿、下降为红。装填用时越短越好，穿深越高越好。车辆身份按类别显示，例如 Donnola 显示金币车 → 收藏车，等级、车型和国籍采用百科的显示名称。科技树以单行标题栏展示标题和百科入口，树图有独立高度，内容放得下时居中，网格等级栏贴底。鼠标拖曳可以横向和纵向移动树图，单击仍可打开坦克详情。
  - 坦克百科详情页删除装饰横幅，车名移入顶部车辆信息卡，方便在首屏浏览车辆配置。
- 版本基线：5.7.5（装甲厚度视图交互与 BlitzKit 外观）。本次为 bundled frontend + 新导航入口，按 Version-as-Code minor 递增。
