# Android 3.22.1

- versionName：3.22.1
- versionCode：3022001（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：patch（Battle Data 出生侧统计并入 summary）
- 最低支持版本：保持现有发布配置，不因本版本抬升。

## 说明

- 管理员 Battle Data 页面从 `GET /api/admin/battle-data/summary` 读取出生侧统计，移除独立的 `spawn-stats` 接口。
- HTTP API 只维护一个版本：后端部署后，3.22.1 之前的 APK 无法加载 Battle Data 管理页，管理员需要更新 APK；普通用户功能不受影响。
