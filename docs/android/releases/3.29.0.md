## 说明

- **地图预览默认 2D**：从地图列表选图后默认进入 2D 战术图；显式 `?mode=3d` 或视图切换仍进入 3D。
- **canonical 2D 战术事实**：显示语义出生点、游戏内可玩边界和基地点位；缺数据 fail-closed，不画猜测值。
- **Playback 2D 对齐的标注工具**：select/route、LT/MT/HT/TD、pen/eraser、arrow/line/rect/circle/text；支持选择、移动、删除、重命名、撤销/重做、清空和显隐。
- **完整 annotation JSON**：per-type fail-closed validator，支持完整 schema 和旧 `-2d`/`-3d` pen-only 文件；3D 仍只接受 pen 几何。
- **当前视角 PNG**：导出 BattleMap viewport，包含底图、出生点、边界、基地和可见标注，不包含页面/toolbar UI；支持打包底图与 map2d blob。
- **2D 全屏**：2D/3D 都提供原生 fullscreen；切到 3D 时自动退出。
- **共享渲染修正**：unit marker 去掉「计划 · class」和暗色底盘；arrow head 随线宽缩放并修正圆头；rect 的 y 投影改用下边界 + 高度。
- **不受影响**：Native Bridge、最低支持版本和 3D annotation 能力不变。
