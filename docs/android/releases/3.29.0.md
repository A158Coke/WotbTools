# Android 3.29.0

- versionName：3.29.0
- versionCode：3029000（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：minor（地图预览 2D 战术工作区：完整标注、序列化、PNG、全屏）
- 最低支持版本：3017007（沿用当前生产门槛，不变）。

## 说明

- **地图预览默认 2D**：从地图列表选图后默认进入 2D 战术图；显式 `?mode=3d` 或视图切换仍进入 3D。
- **规范地图语义的 2D 战术事实**：显示语义出生点、游戏内可玩边界和基地点位；缺数据 fail-closed，不画猜测值。
- **与回放 2D 对齐的标注工具**：选择/路线、轻坦 LT/中坦 MT/重坦 HT/歼坦 TD、画笔/橡皮、箭头/直线/矩形/圆形/文字；支持选择、移动、删除、重命名、撤销/重做、清空和显隐。
- **完整标注 JSON**：按类型 fail-closed 校验，支持完整数据结构和旧 `-2d`/`-3d` 仅含画笔文件；3D 仍只接受画笔几何。
- **当前视角 PNG**：导出 BattleMap 视口，包含底图、出生点、边界、基地和可见标注，不包含页面/工具栏 UI；支持打包底图与 map2d 资源包底图。
- **2D 全屏**：2D/3D 都提供原生全屏；切到 3D 时自动退出。
- **共享渲染修正**：计划点标记去掉「计划 · 车型」和暗色底盘；箭头头部随线宽缩放并修正圆头；矩形 y 投影改用下边界加高度。
- **不受影响**：Native Bridge、最低支持版本和 3D 标注能力不变。
