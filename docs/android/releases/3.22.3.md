# Android 3.22.3

- versionName：3.22.3
- versionCode：3022003（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：patch（Battle Data 出生侧统计并入 summary；admin-only API breaking，不抬门槛）
- 最低支持版本：保持现有发布配置，不因本版本抬升。

## 说明

- 管理员 Battle Data 页面从 `GET /api/admin/battle-data/summary` 读取出生侧统计，移除独立的 `spawn-stats` 接口。
- 后端部署后，3.22.3 之前的 APK 无法加载 Battle Data 管理页，管理员更新 APK 即可；普通用户功能不受影响。
