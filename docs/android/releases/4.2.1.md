# Android 4.2.1

- versionName：4.2.1
- versionCode：4002001（由 `wotbVersion` 推导）
- Native Bridge：v3（不变）
- 类型：patch（装甲查看器射击方/受击方主炮配置解耦 + 显式 `scfg` 空弹表回退与 HUD 同口径；影响范围限于装甲查看器页面，`penetration.js` 判定算法、回放权威输入与装甲 shader 均未改动）
- 最低支持版本：保持 4.1.0 / 4001000，不因本版本抬升。

## 说明

- **射击方/受击方主炮配置解耦**：受击方切换主炮/配置不再改变射击方的弹表、口径与选中弹种——即使双方是同一 Tank ID。射击方配置只认显式 `scfg`，缺省用射击方自身默认顶级配置（`configs` 末位），与 `ArmorShotHud` / `ArmorSideConfig` / `fetchShells` 缺省口径一致。
- **显式 `scfg` 空弹表回退统一**：显式 `scfg` 指向 `shells=[]` 的合法配置时，场景判定与 HUD 一致回退车辆顶层 `shells`（不跳默认配置）；`scfg` 改为严格数值解析，消除 `parseInt` 与 HUD `Number.isInteger` 的分歧。口径与弹表同源解析，缺失口径维持 fail-closed。
- Web bundle 随 APK 打包；Agent WASM pin 不变。发布说明在发布时归档。
