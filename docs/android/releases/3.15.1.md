# Android 3.15.1

- versionName：3.15.1
- versionCode：3015001
- 变更等级：patch。仅调整随 APK 打包的 frontend telemetry：`/download/android` 页面本身不再计入 Android download 指标，只有最终「下载 APK」按钮点击发送独立 `android_download_click` 事件；不改变下载链路、用户功能、Native 能力或任何 wire bridge 行为。
- Native Bridge：保持 v3，RPC、本地 origin 和通信契约不变；`contracts/android-native-bridge.json` 不改。
- 最低支持版本：保持现行 `ANDROID_MIN_SUPPORTED_VERSION_CODE`；本候选与线上同 major，不因该 telemetry 小修抬高强制更新门槛。

本 PR 修改会进入 APK 的 bundled frontend，因此按 Android Version-as-Code 规则从父提交的 **3.15.0 / 3015000** 递增为 **3.15.1 / 3015001**。这只声明新的 Android 候选 identity，不代表已 stage、真机验收或 publish；后续仍按标准发布流程执行。

# Android 下载 telemetry

Web `/download/android` 页面打开本身不计数。最终「下载 APK」按钮点击立即 best-effort 上报 `android_download_click`，不进入普通 5 秒 usage queue；telemetry 失败不阻塞 APK 导航。旧 `feature_open/android_download` 页面打开数据和旧 frontend HTTP 200/206 APK 请求数据均不并入新指标。

# 验证

- Frontend 组件测试：页面加载不计数；最终下载按钮每次点击各上报一次 `android_download_click`（重复点击不去重）；telemetry 同步抛错或异步失败都不阻止 APK 导航；manifest 失败和未登录流程不产生下载点击事件。
- HTTP contract：`contracts/http/openapi.yaml` 使用 `oneOf` 专用事件分支（`AndroidDownloadClickEvent`）约束 `android_download_click` 只能是 `platform=web + feature=android_download`，并禁止 `operation_id` / `outcome` / `error_code` / `error_id`；generated validators/types 由 `npm run api:generate` 生成。
- Backend：接受精确 click tuple 和滚动兼容的旧 `feature_open/android_download`；拒绝 Android platform、错误 feature 及所有 replay-only / 未知字段。
- Grafana：Android Downloads 只查询 `telemetry_event="android_download_click"`，不读取旧 page-open / 200 / 206 数据。
